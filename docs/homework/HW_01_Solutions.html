Problem 1: Sampling Distribution of the Sample Mean

Researchers are studying the birth weights of full-term infants at a large hospital. Let \(X_1, X_2, \ldots, X_{n}\) be a random sample of birth weights from a population with mean \(\mu = 3400\) grams and standard deviation \(\sigma = 450\) grams.

Part (a)

For a sample of size \(n = 25\), calculate \(E(\bar{X})\), \(\text{Var}(\bar{X})\), and \(SE(\bar{X})\).

Solution:

Using the properties of the sample mean from a random sample that we explored in class:

\[E(\bar{X}) = \mu = 3400 \text{ grams}\]

\[\text{Var}(\bar{X}) = \frac{\sigma^2}{n} = \frac{450^2}{25} = \frac{202500}{25} = 8100 \text{ grams}^2\]

\[SE(\bar{X}) = \sqrt{\text{Var}(\bar{X})} = \frac{\sigma}{\sqrt{n}} = \frac{450}{\sqrt{25}} = \frac{450}{5} = 90 \text{ grams}\]

mu <- 3400
sigma <- 450
n <- 25

E_Xbar <- mu
Var_Xbar <- sigma^2 / n
SE_Xbar <- sigma / sqrt(n)

  Quantity = c("$E(\\bar{X})$", "$\\text{Var}(\\bar{X})$", "$SE(\\bar{X})$"),
  Value = c(E_Xbar, Var_Xbar, SE_Xbar),
  Units = c("grams", "grams$^2$", "grams")
) |> knitr::kable(escape = FALSE)

Part (b)

How large must the sample size \(n\) be so that the standard error of \(\bar{X}\) is at most 50 grams?

Solution:

We need \(SE(\bar{X}) \leq 50\):

\[\frac{\sigma}{\sqrt{n}} \leq 50\]

\[\sqrt{n} \geq \frac{\sigma}{50} = \frac{450}{50} = 9\]

\[n \geq 81\]

cat("Verification: SE with n =", ceiling(n_required), "is", sigma/sqrt(ceiling(n_required)), "grams")

Answer: The sample size must be at least \(n = 81\).

Part (c)

Suppose we define a new statistic \(W = \frac{1}{n}\sum_{i=1}^{n} (X_i - 3000)\). Find \(E(W)\) and \(\text{Var}(W)\).

Solution:

First, simplify \(W\):

\[W = \frac{1}{n}\sum_{i=1}^{n} (X_i - 3000) = \frac{1}{n}\sum_{i=1}^{n} X_i - \frac{1}{n}\sum_{i=1}^{n} 3000 = \bar{X} - 3000\]

Now find the expected value:

\[E(W) = E(\bar{X} - 3000) = E(\bar{X}) - 3000 = \mu - 3000\]

For the variance (constants don’t affect variance):

\[\text{Var}(W) = \text{Var}(\bar{X} - 3000) = \text{Var}(\bar{X}) = \frac{\sigma^2}{n}\]

Is \(W\) an unbiased estimator of \(\mu - 3000\)?

Yes! Since \(E(W) = \mu - 3000\), the estimator \(W\) is unbiased for \(\mu - 3000\).

cat("Var(W) = σ²/n =", Var_W, "grams²\n")
Var(W) = σ²/n = 8100 grams²
cat("W is an unbiased estimator of μ - 3000 since E(W) = μ - 3000")

Problem 2: Bias, Variance, and MSE

Let \(X_1, X_2, \ldots, X_n\) be a random sample from an Exponential distribution with rate parameter \(\lambda > 0\) (so that \(E(X_i) = 1/\lambda\) and \(\text{Var}(X_i) = 1/\lambda^2\)).

Part (a)

Show that \(\hat{\mu} = \bar{X}\) is unbiased for \(\mu = 1/\lambda\) and calculate \(\text{Var}(\hat{\mu})\).

Solution:

Unbiasedness:

\[E(\hat{\mu}) = E(\bar{X}) = E\left(\frac{1}{n}\sum_{i=1}^{n} X_i\right) = \frac{1}{n}\sum_{i=1}^{n} E(X_i) = \frac{1}{n} \cdot n \cdot \frac{1}{\lambda} = \frac{1}{\lambda} = \mu\]

Since \(E(\hat{\mu}) = \mu\), the estimator \(\bar{X}\) is unbiased for \(\mu = 1/\lambda\).

Variance:

\[\text{Var}(\hat{\mu}) = \text{Var}(\bar{X}) = \frac{\text{Var}(X_i)}{n} = \frac{1/\lambda^2}{n} = \frac{1}{n\lambda^2}\]

Part (b)

For \(\hat{\lambda} = 1/\bar{X}\), given that \(E(1/\bar{X}) = \frac{n\lambda}{n-1}\) for \(n > 1\), calculate the bias and propose an unbiased modification.

Solution:

Bias of \(\hat{\lambda}\):

\[\text{Bias}(\hat{\lambda}) = E(\hat{\lambda}) - \lambda = \frac{n\lambda}{n-1} - \lambda = \frac{n\lambda - (n-1)\lambda}{n-1} = \frac{\lambda}{n-1}\]

The bias is positive, meaning \(\hat{\lambda} = 1/\bar{X}\) systematically overestimates \(\lambda\).

Unbiased modification:

To create an unbiased estimator, we need to multiply by a correction factor:

\[\tilde{\lambda} = \frac{n-1}{n} \cdot \frac{1}{\bar{X}} = \frac{n-1}{n\bar{X}}\]

Verification:

\[E(\tilde{\lambda}) = \frac{n-1}{n} \cdot E\left(\frac{1}{\bar{X}}\right) = \frac{n-1}{n} \cdot \frac{n\lambda}{n-1} = \lambda \checkmark\]

Part (c)

For \(n = 12\) and \(\lambda = 0.5\), calculate the bias and MSE of \(\hat{\lambda} = 1/\bar{X}\).

Solution:

\[\text{MSE}(\hat{\lambda}) = \text{Var}(\hat{\lambda}) + [\text{Bias}(\hat{\lambda})]^2 = 0.02975 + 0.04545^2 \approx 0.02975 + 0.00207 \approx 0.03182\]

Problem 3: The Bias-Variance Tradeoff

A hospital infection control team wants to estimate the proportion \(p\) of patients who develop hospital-acquired infections.

  • Standard estimator: \(\hat{p}_1 = \frac{X}{n}\)
  • “Add-one” estimator: \(\hat{p}_2 = \frac{X + 1}{n + 2}\)

Part (a)

Show that \(\hat{p}_1\) is unbiased for \(p\) and find its variance.

Solution:

Since \(X \sim \text{Binomial}(n, p)\), we have \(E(X) = np\).

\[E(\hat{p}_1) = E\left(\frac{X}{n}\right) = \frac{E(X)}{n} = \frac{np}{n} = p\]

Since \(E(\hat{p}_1) = p\), the estimator \(\hat{p}_1\) is unbiased.

Variance:

\[\text{Var}(\hat{p}_1) = \text{Var}\left(\frac{X}{n}\right) = \frac{\text{Var}(X)}{n^2} = \frac{np(1-p)}{n^2} = \frac{p(1-p)}{n}\]

Part (b)

Calculate \(E(\hat{p}_2)\) and find its bias.

Solution:

\[E(\hat{p}_2) = E\left(\frac{X + 1}{n + 2}\right) = \frac{E(X) + 1}{n + 2} = \frac{np + 1}{n + 2}\]

Bias:

\[\text{Bias}(\hat{p}_2) = E(\hat{p}_2) - p = \frac{np + 1}{n + 2} - p = \frac{np + 1 - p(n + 2)}{n + 2} = \frac{np + 1 - np - 2p}{n + 2} = \frac{1 - 2p}{n + 2}\]

Interpretation:

  • When \(p < 0.5\): Bias \(= \frac{1-2p}{n+2} > 0\), so \(\hat{p}_2\) overestimates \(p\) (pulls toward 0.5)
  • When \(p > 0.5\): Bias \(= \frac{1-2p}{n+2} < 0\), so \(\hat{p}_2\) underestimates \(p\) (pulls toward 0.5)
  • When \(p = 0.5\): Bias \(= 0\)

The add-one estimator shrinks estimates toward 0.5.

Part (c)

For \(n = 40\) and \(p = 0.05\), calculate MSE of both estimators.

Solution:

n <- 40
p <- 0.05

# Standard estimator p̂₁ = X/n

mse_p1 <- var_p1  # unbiased, so MSE = Variance

bias_p2 <- (1 - 2*p) / (n + 2)

mse_p2 <- var_p2 + bias_p2^2

) |>
  mutate(across(where(is.numeric), \(x) round(x, 6))) |>
  knitr::kable(escape = FALSE)

Comparison:

Plot comparing MSE across all values of \(p\).

The add-one estimator outperforms the standard estimator for p ∈ ( 0.15 , 0.85 )

Answer: The add-one estimator has lower MSE for \(p\) approximately in the range \((0.10, 0.90)\). For extreme values of \(p\) (near 0 or 1), the standard estimator is preferred.

Additional info: Why does this work? The add-one estimator introduces bias but reduces variance for moderate values of \(p\) and so it has lower MSE. Interestingly, this is actually the posterior mean under a uniform Beta(1,1) prior for a Bayesian analysis. This is equivalent to starting with a “prior belief” of observing 1 success and 1 failure before collecting data, and this “regularization” (shrinkage toward 0.5) prevents extreme estimates (like \(\hat{p} = 0\) or \(\hat{p} = 1\)) that can occur with small samples.

The add-one estimator is a bias-variance tradeoff that pays off when the true proportion is moderate. It’s a form of shrinkage estimation that sacrifices unbiasedness for improved overall accuracy (lower MSE) in the “middle” of the parameter space.

Problem 4: Sample Variance Estimators

Consider two estimators for \(\sigma^2\):

\[S^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2 \quad \text{and} \quad \tilde{S}^2 = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^2\]

Part (a)

Find \(E(\tilde{S}^2)\) and calculate its bias.

Solution:

Note that \(\tilde{S}^2 = \frac{n-1}{n} S^2\) since:

\[\tilde{S}^2 = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^2 = \frac{n-1}{n} \cdot \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2 = \frac{n-1}{n} S^2\]

Therefore:

\[E(\tilde{S}^2) = E\left(\frac{n-1}{n} S^2\right) = \frac{n-1}{n} E(S^2) = \frac{n-1}{n} \sigma^2\]

Bias:

\[\text{Bias}(\tilde{S}^2) = E(\tilde{S}^2) - \sigma^2 = \frac{n-1}{n}\sigma^2 - \sigma^2 = \frac{(n-1) - n}{n}\sigma^2 = -\frac{\sigma^2}{n}\]

The bias is negative, meaning \(\tilde{S}^2\) systematically underestimates \(\sigma^2\).

Part (b)

For \(n = 8\) and \(\sigma^2 = 64\), calculate the bias.

Solution:

n <- 8

Bias(S̃²) = -8 
cat("Percentage of true variance:", abs(bias_S2_tilde) / sigma_sq * 100, "%\n")
Percentage of true variance: 12.5 %

Answer:

  • \(E(\tilde{S}^2) = \frac{7}{8} \times 64 = 56\)
  • Bias\((\tilde{S}^2) = -\frac{64}{8} = -8\)
  • This bias represents \(\frac{8}{64} \times 100\% = 12.5\%\) of the true variance.

Problem 5: Estimating Vaccine Efficacy

Part (a)

In a pilot study, \(n = 60\) vaccinated individuals are tested, and \(X = 51\) show immunity.

Solution:

n <- 60
x <- 51

# Point estimate
p_hat <- x / n

# Estimated standard error
se_hat <- sqrt(p_hat * (1 - p_hat) / n)

cat("Point estimate p̂ =", p_hat, "\n")
Point estimate p̂ = 0.85 
cat("Estimated standard error SE(p̂) =", round(se_hat, 4), "\n")
Estimated standard error SE(p̂) = 0.0461

Calculations:

\[\hat{p} = \frac{X}{n} = \frac{51}{60} = 0.85\]

\[\widehat{SE}(\hat{p}) = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \sqrt{\frac{0.85 \times 0.15}{60}} = \sqrt{\frac{0.1275}{60}} = \sqrt{0.002125} \approx 0.0461\]

Part (b)

If the true efficacy is \(p = 0.80\), calculate the theoretical MSE and SE.

Solution:

p_true <- 0.80
n <- 60

# Since p̂ is unbiased, MSE = Variance
var_p_hat <- p_true * (1 - p_true) / n
mse_p_hat <- var_p_hat  # unbiased
se_p_hat <- sqrt(var_p_hat)

cat("Theoretical Variance =", round(var_p_hat, 6), "\n")
Theoretical Variance = 0.002667 
cat("Theoretical MSE =", round(mse_p_hat, 6), "\n")
Theoretical MSE = 0.002667 
cat("Theoretical SE =", round(se_p_hat, 4), "\n")
Theoretical SE = 0.0516

Calculations:

\[\text{Var}(\hat{p}) = \frac{p(1-p)}{n} = \frac{0.80 \times 0.20}{60} = \frac{0.16}{60} = 0.002\overline{6}\]

Since \(\hat{p}\) is unbiased: \[\text{MSE}(\hat{p}) = \text{Var}(\hat{p}) = 0.002\overline{6}\]

\[SE(\hat{p}) = \sqrt{\text{Var}(\hat{p})} = \sqrt{0.002\overline{6}} \approx 0.0516\]

Part (c)

Find minimum sample size for \(SE \leq 0.04\), assuming \(p \approx 0.85\).

Solution:

We need: \[SE(\hat{p}) = \sqrt{\frac{p(1-p)}{n}} \leq 0.04\]

\[\frac{p(1-p)}{n} \leq 0.0016\]

\[n \geq \frac{p(1-p)}{0.0016}\]

p_plan <- 0.85
target_se <- 0.04

n_required <- p_plan * (1 - p_plan) / (target_se^2)

cat("Minimum sample size required:", ceiling(n_required), "\n")
Minimum sample size required: 80 
cat("Verification: SE with n =", ceiling(n_required), "is", 
    round(sqrt(p_plan * (1 - p_plan) / ceiling(n_required)), 4), "\n")
Verification: SE with n = 80 is 0.0399

Calculation:

Problem 6: Devore et al. Section 7.1 Exercise 22

Consider the adjusted estimator:

\[\hat{P} = \frac{X + \sqrt{n/4}}{n + \sqrt{n}}\]

where \(X \sim \text{Binomial}(n, p)\).

Part (a)

Determine the MSE of this estimator.

Solution:

Step 1: Find \(E(\hat{P})\)

\[E(\hat{P}) = \frac{E(X) + \sqrt{n/4}}{n + \sqrt{n}} = \frac{np + \frac{\sqrt{n}}{2}}{n + \sqrt{n}}\]

Factor out \(\sqrt{n}\):

\[E(\hat{P}) = \frac{\sqrt{n}\left(\sqrt{n}p + \frac{1}{2}\right)}{\sqrt{n}(\sqrt{n} + 1)} = \frac{\sqrt{n}p + \frac{1}{2}}{\sqrt{n} + 1}\]

Step 2: Find the bias

\[\text{Bias}(\hat{P}) = E(\hat{P}) - p = \frac{\sqrt{n}p + \frac{1}{2}}{\sqrt{n} + 1} - p\]

\[= \frac{\sqrt{n}p + \frac{1}{2} - p(\sqrt{n} + 1)}{\sqrt{n} + 1} = \frac{\sqrt{n}p + \frac{1}{2} - \sqrt{n}p - p}{\sqrt{n} + 1} = \frac{\frac{1}{2} - p}{\sqrt{n} + 1}\]

Step 3: Find the variance

\[\text{Var}(\hat{P}) = \frac{\text{Var}(X)}{(n + \sqrt{n})^2} = \frac{np(1-p)}{n(\sqrt{n} + 1)^2} = \frac{p(1-p)}{(\sqrt{n} + 1)^2}\]

Step 4: Calculate MSE

\[\text{MSE}(\hat{P}) = \text{Var}(\hat{P}) + [\text{Bias}(\hat{P})]^2\]

\[= \frac{p(1-p)}{(\sqrt{n} + 1)^2} + \frac{(\frac{1}{2} - p)^2}{(\sqrt{n} + 1)^2}\]

\[= \frac{p(1-p) + \left(\frac{1}{2} - p\right)^2}{(\sqrt{n} + 1)^2}\]

Expand the numerator: \[p(1-p) + \left(\frac{1}{2} - p\right)^2 = p - p^2 + \frac{1}{4} - p + p^2 = \frac{1}{4}\]

Therefore:

\[\boxed{\text{MSE}(\hat{P}) = \frac{1/4}{(\sqrt{n} + 1)^2} = \frac{1}{4(\sqrt{n} + 1)^2}}\]

What is interesting?

The MSE does not depend on \(p\)! For most proportion estimators, the MSE depends on the unknown value of \(p\). This is another Bayesian-derived estimator (posterior mean under a Beta(\(\sqrt{n}/2\), \(\sqrt{n}/2\))) and it results in MSE across all values of \(p\).

Part (b)

Compare to the usual estimator \(\hat{p} = X/n\).

Solution:

The usual estimator has: \[\text{MSE}(\hat{p}) = \frac{p(1-p)}{n}\]

which depends on \(p\) and is maximized at \(p = 0.5\) where \(\text{MSE}(\hat{p}) = \frac{0.25}{n}\).

n_values <- c(16, 36, 64, 100)

mse_data <- crossing(
  p = seq(0.01, 0.99, by = 0.01),
  n = n_values
) |>
  mutate(
    mse_usual = p * (1 - p) / n,
    mse_bayesian = 1 / (4 * (sqrt(n) + 1)^2),
    n_label = paste("n =", n)
  )

mse_data |>
  pivot_longer(cols = c(mse_usual, mse_bayesian), names_to = "Estimator", values_to = "MSE") |>
  mutate(Estimator = ifelse(Estimator == "mse_usual", "Usual (X/n)", "Bayesian-Adjusted")) |>
  ggplot(aes(x = p, y = MSE, color = Estimator, linetype = Estimator)) +
  geom_line(linewidth = 1) +
  facet_wrap(~n_label, scales = "free_y") +
  scale_color_manual(values = c("darkred", "steelblue")) +
  labs(
    title = "MSE Comparison: Usual vs. Bayesian-Adjusted Estimator",
    subtitle = "Bayesian estimator has constant MSE (horizontal line)",
    x = "True Proportion (p)",
    y = "Mean Squared Error"
  ) +
  theme(legend.position = "top")

Conclusions:

  1. The Bayesian-adjusted estimator has constant MSE regardless of \(p\) (shown as horizontal lines).

  2. The usual estimator has MSE that varies with \(p\), maximized at \(p = 0.5\).

  3. For moderate values of \(p\) (roughly between 0.15 and 0.85 depending on \(n\)), the Bayesian estimator has lower MSE.

  4. For extreme values of \(p\) (near 0 or 1), the usual estimator is preferred.

  5. As \(n\) increases, both MSEs decrease, but the crossover points shift, with the Bayesian estimator winning over a narrower range of \(p\) values.

  6. The constant-MSE property is particularly valuable when we have no prior information about \(p\), as it provides a “minimax” type guarantee.
