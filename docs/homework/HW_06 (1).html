Problem 1: Neyman-Pearson Lemma for Exponential Data (Lesson 15)

In a post-market drug safety study, the time (in months) between serious adverse events follows an Exponential distribution with rate \(\lambda\). A higher rate means events occur more frequently, signaling greater risk.

Let \(X_1, \ldots, X_n \stackrel{iid}{\sim} \text{Exponential}(\lambda)\), so \(f(x; \lambda) = \lambda e^{-\lambda x}\) for \(x > 0\). We test: \[H_0: \lambda = \lambda_0 \qquad \text{vs} \qquad H_a: \lambda = \lambda_a\] where \(\lambda_a > \lambda_0\).

(a) Write out the likelihood ratio \(\Lambda^* = L(\lambda_a) / L(\lambda_0)\) for a sample \(x_1, \ldots, x_n\). Simplify as much as possible.

(b) By the Neyman-Pearson Lemma, the most powerful test rejects \(H_0\) when \(\Lambda^* \geq k\). Show that this rejection region is equivalent to: \[\sum_{i=1}^n x_i \leq c\] for some constant \(c\). Interpret this intuitively: why should a small total time between adverse events serve as evidence against the null hypothesis?

(c) Under \(H_0\), we have \(\sum_{i=1}^n X_i \sim \text{Gamma}(n, \lambda_0)\). Write an expression for the critical value \(c\) that gives the test exactly level \(\alpha\). (Express \(c\) using a quantile of the Gamma distribution.)

(d) Suppose \(\lambda_0 = 0.5\), \(\lambda_a = 1.0\), \(n = 8\), and \(\alpha = 0.05\). Use R to compute the critical value \(c\), the Type II error \(\beta\), and the power \(1 - \beta\).

(e) Explain in 2–3 sentences what the Neyman-Pearson guarantee means in the drug safety monitoring context, and why the directionality (\(\lambda_a > \lambda_0\)) is essential to the UMP argument in Problem 2.

Problem 2: Power Function and UMP Test (Lesson 15)

Continue with the exponential setting of Problem 1 but now with a composite alternative \(H_a: \lambda > \lambda_0\).

(a) Argue that the test “reject when \(\sum X_i \leq c\)” (with \(c\) chosen to give level \(\alpha\) under \(H_0: \lambda = \lambda_0\)) is UMP for \(H_0: \lambda \leq \lambda_0\) vs \(H_a: \lambda > \lambda_0\). What property of the NP rejection region makes it work for every \(\lambda_a > \lambda_0\)?

(b) Write down the power function \(\pi(\lambda')\) for this test. (Hint: express it using the CDF of a \(\text{Gamma}(n, \lambda')\) distribution.)

(c) Using R with \(\lambda_0 = 0.5\), \(n = 8\), \(\alpha = 0.05\): plot \(\pi(\lambda')\) for \(\lambda' \in [0.3, 2.5]\). Mark \(\lambda_0 = 0.5\) with a vertical dashed line and \(\alpha = 0.05\) with a horizontal dashed line. Label axes using expression().

(d) From your plot, approximately what value of \(\lambda'\) is needed to achieve power \(\geq 0.80\)? What does this say about whether \(n = 8\) is adequate for detecting a doubling of the hazard rate from 0.5 to 1.0?

Problem 3: Likelihood Ratio Test for a Poisson Rate (Lesson 15)

During a Phase II oncology trial, the number of Grade 3+ adverse events per 100 patient-weeks is modeled as \(X_1, \ldots, X_n \stackrel{iid}{\sim} \text{Poisson}(\lambda)\) over \(n\) monitoring windows. We test: \[H_0: \lambda = \lambda_0 \qquad \text{vs} \qquad H_a: \lambda \neq \lambda_0\]

(a) Derive the LRT statistic \(\Lambda = L(\hat\lambda_0) / L(\hat\lambda_{mle})\). Show that \(\hat\lambda_{mle} = \bar{x}\) and simplify \(\Lambda\) as much as possible.

(b) How many degrees of freedom does the Wilks chi-squared approximation have? Justify by counting free parameters in \(\Omega\) vs \(\Omega_0\).

(c) Suppose \(n = 20\) and \(\sum x_i = 34\), with historical baseline \(\lambda_0 = 1.5\). In R:

  • Compute \(\hat\lambda_{mle}\), \(\Lambda\), and \(-2\ln(\Lambda)\)
  • Find the p-value from the \(\chi^2_1\) approximation
  • Compare to the exact p-value from poisson.test()
  • Comment on the quality of the large-sample approximation here

(d) Repeat part (c) with \(n = 5\) and \(\sum x_i = 11\). Does Wilks’ approximation perform well? What does this illustrate about applying Wilks’ theorem?

Problem 4: Statistical vs. Practical Significance (Lesson 16)

A large RCT (\(n = 4{,}000\)) of a new antidiabetic drug reports:

  • Mean HbA1c reduction: \(\bar{x} = 0.22\) percentage points
  • Sample standard deviation: \(s = 2.10\) percentage points
  • Two-sided p-value: \(p = 0.0093\)

The minimum clinically important difference (MCID) for this drug class is \(\geq 0.5\) percentage points.

(a) Compute the 95% CI for mean HbA1c reduction. Show your work.

(b) Compute Cohen’s \(d = \bar{x}/s\). Classify the effect size using the conventions from the lecture slides (negligible \(< 0.2\); small \(0.2\)–\(0.5\); medium \(0.5\)–\(0.8\); large \(> 0.8\)).

(c) The control group had a mean HbA1c reduction of \(0.01\) pp (\(s_c = 2.05\) pp). Treating the outcome as binary — “achieved \(\geq 1\) pp reduction” — use a normal approximation (\(P(\text{reduction} \geq 1) \approx 1 - \Phi((1 - \mu)/s)\)) to estimate the proportion achieving this threshold in each group, and compute the NNT.

(d) Is the result statistically significant? Is it clinically meaningful? What should the authors report per CONSORT guidelines?

(e) If only \(n = 80\) patients had been enrolled (same \(\bar{x}\) and \(s\)), would the result be statistically significant at \(\alpha = 0.05\)? Compute the p-value. What does this contrast illustrate?

Problem 5: CI-Test Duality — Inverting the Chi-Squared Test (Lesson 16)

(a) Let \(X_1, \ldots, X_n \stackrel{iid}{\sim} N(\mu, \sigma^2)\) with \(\sigma^2\) unknown. For testing \(H_0: \sigma^2 = \sigma^2_0\) vs \(H_a: \sigma^2 \neq \sigma^2_0\), the level-\(\alpha\) acceptance region is: \[A(\sigma^2_0) = \left\{\chi^2_{1-\alpha/2,\, n-1} \;\leq\; \frac{(n-1)S^2}{\sigma^2_0} \;\leq\; \chi^2_{\alpha/2,\, n-1}\right\}\] Write this acceptance region out explicitly and verify that it is an acceptance region (i.e., \(P_{\sigma^2_0}(\text{data} \in A(\sigma^2_0)) = 1 - \alpha\)).

(b) Invert the acceptance region to derive the \(100(1-\alpha)\%\) confidence interval for \(\sigma^2\). Show all algebraic steps, paying attention to how the chi-squared quantiles appear in the bounds and why the larger quantile gives the lower CI bound.

(c) By the duality theorem, state what it means for \(\sigma^2_0 = 9\) to be inside this CI, without doing any computation.

(d) A QC lab measures drug potency (mg/tablet) for \(n = 12\) tablets and finds \(s^2 = 4.86\).

  • Compute the 95% CI for \(\sigma^2\) and \(\sigma\) using R
  • Test \(H_0: \sigma^2 = 4\) vs \(H_a: \sigma^2 \neq 4\) at \(\alpha = 0.05\) using both the chi-squared p-value approach and the CI-duality approach
  • Verify the two approaches give identical conclusions

Problem 6: One-Sided Duality and Multiple Testing (Lesson 16)

Part A — One-Sided Duality

A cardiovascular trial tests whether a new statin reduces mean LDL below a reference value of \(\mu_0 = 130\) mg/dL. From \(n = 25\) patients: \(\bar{x} = 121.4\) mg/dL, \(s = 18.3\) mg/dL.

(a) State the appropriate one-sided hypotheses (\(H_0\) and \(H_a\)).

(b) Compute the 95% lower confidence bound \(\underline{\mu} = \bar{x} - t_{0.05,\, 24} \cdot s/\sqrt{n}\). Using the one-sided duality theorem, state what this bound implies about the hypothesis test at level \(\alpha = 0.05\).

(c) Explain why using a 95% two-sided CI (i.e., checking whether \(\mu_0 = 130\) falls outside it) is the wrong approach for this one-sided test at \(\alpha = 0.05\). What effective significance level does that correspond to?

Part B — Multiple Testing

A Phase III trial reports \(m = 6\) pre-specified endpoints, each tested at \(\alpha = 0.05\) using individual 95% CIs.

(d) Assuming all null hypotheses are true and tests are independent, compute the probability that at least one CI fails to capture its true parameter (exact formula, not Bonferroni).

(e) What Bonferroni-corrected level \(\alpha^* = \alpha/m\) should each test use to control the familywise error rate at 0.05? What CI coverage does this correspond to?

(f) In R, the six standardized estimates (Est/SE) are: \[z = (2.45,\; 1.82,\; 0.95,\; -0.33,\; 2.11,\; 1.55)\] Construct individual 95% CIs and Bonferroni-adjusted 95% simultaneous CIs for all six endpoints. Produce a forest plot. Which endpoints are significant under each approach?

Problem 7: Bootstrap Hypothesis Testing (Lesson 17)

Serum ferritin (ng/mL) was measured in \(n = 18\) hospitalized patients with suspected iron-deficiency anemia. The clinical lower limit of normal is \(\mu_0 = 30\) ng/mL. We test \(H_0: \mu = 30\) vs \(H_a: \mu \neq 30\).

ferritin <- c(12.4, 28.1,  8.7, 35.2, 19.6, 14.3, 41.8, 22.5,
               9.1, 17.8, 31.4, 11.2, 24.6, 16.9, 38.7, 13.5,
              20.1, 27.3)
mu_0 <- 30

(a) Compute the sample mean and SD. Run t.test() and report the p-value and conclusion at \(\alpha = 0.05\).

(b) Plot a histogram and Q-Q plot. Does normality seem reasonable for these data?

(c) Implement the correct bootstrap hypothesis test with \(B = 9{,}999\) resamples: 1. Shift the data so \(\bar{x}^* = \mu_0\): \(x_i^* = x_i - \bar{x} + \mu_0\) 2. For each bootstrap resample from \(x^*\), compute the t-statistic \(T^{*b}\) 3. p-value = fraction of \(|T^{*b}| \geq |T_{\text{obs}}|\)

Report the bootstrap p-value and compare to the t-test.

(d) Implement the naive (incorrect) bootstrap: resample from the original unshifted data and compare the resampled means to \(\bar{x}\) (not \(\mu_0\)). Report this p-value and explain why this is invalid.

(e) Construct a 95% percentile bootstrap CI for \(\mu\) (resample from original data). Does \(\mu_0 = 30\) fall inside or outside the CI? Is this consistent with the test from part (c)? What does this demonstrate about CI-test duality for bootstrap methods?

(f) Given what you learned from the Lesson 17 simulation study, would you expect larger differences between the t-test and bootstrap test for these data at larger or smaller sample sizes? For more symmetric or more skewed data?

Problem 8: Textbook Problem — UMP Tests (Devore 9.5 style)

Let \(X_1, \ldots, X_n \stackrel{iid}{\sim} N(\mu, \sigma^2)\) with \(\sigma^2\) known. Test \(H_0: \mu = \mu_0\) vs \(H_a: \mu = \mu_a\) where \(\mu_a > \mu_0\).

(a) Show that the NP most powerful test has rejection region \(\bar{X} \geq c\) for some constant \(c\).

(b) Show that the power against the specific alternative \(\mu_a\) is: \[\pi(\mu_a) = \Phi\!\left(\frac{\mu_a - \mu_0}{\sigma/\sqrt{n}} - z_\alpha\right)\]

(c) Since this rejection region does not depend on the particular value of \(\mu_a > \mu_0\), what does the Neyman-Pearson Lemma imply about the test’s UMP status for the composite alternative \(H_a: \mu > \mu_0\)?

(d) For \(\mu_0 = 100\), \(\sigma = 15\), \(n = 36\), \(\alpha = 0.05\): compute the power against \(\mu_a = 105\) and \(\mu_a = 110\).

Problem 9: Textbook Problem — The p-Value Function (Devore 9.6 style)

The p-value function \(p(\mu_0)\) plots the two-sided one-sample t-test p-value as a function of the null value \(\mu_0\).

(a) At what value of \(\mu_0\) is \(p(\mu_0)\) maximized? What is the maximum? Explain why.

(b) The 95% CI is exactly the set of \(\mu_0\) values where \(p(\mu_0) \geq 0.05\). What CI corresponds to the set where \(p(\mu_0) \geq 0.01\)?

(c) For a sample of \(n = 20\) from a normal population with \(\bar{x} = 48.3\) and \(s = 6.1\): plot \(p(\mu_0)\) for \(\mu_0 \in [40, 57]\) in R. Shade the 95% CI region. Add a horizontal dashed line at \(p = 0.05\). Verify that the boundaries of the shaded region match the 95% t-interval.
