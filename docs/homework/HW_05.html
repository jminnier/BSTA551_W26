Problem 1: Hypothesis Testing Framework (Lesson 12, Devore 9.1)

A hospital is evaluating a new blood pressure monitoring device. Based on a large historical dataset, resting systolic blood pressure in healthy adults follows a Normal distribution. The current standard monitoring protocol has a known mean of \(\mu_0 = 120\) mmHg with known standard deviation \(\sigma = 15\) mmHg. Clinicians suspect the new device reads systematically higher than the true value.

A validation study measures \(n = 36\) healthy adults with the new device and obtains a sample mean of \(\bar{x} = 124.5\) mmHg.

(a) State the null and alternative hypotheses formally. Is this a one-sided or two-sided test? Justify your choice based on the clinical context.

(b) The test statistic is \(Z = \dfrac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}\). State the distribution of \(Z\) under \(H_0\) and compute its observed value \(z_{\text{obs}}\).

(c) Using a significance level of \(\alpha = 0.05\), find the rejection region. Does the test reject \(H_0\)?

(d) Define Type I error and Type II error in the context of this specific problem (not just in abstract terms). What is the Type I error rate for this test?

(e) The hospital board argues that falsely concluding the device is biased when it is actually accurate would be very costly (they would discard the device). With this in mind, would you recommend using \(\alpha = 0.01\) or \(\alpha = 0.10\)? Explain briefly.

Problem 3: Test for a Proportion (Lesson 13, Devore 9.3)

A large multicenter clinical trial reports that the 30-day readmission rate for patients with heart failure treated under the standard care protocol is \(p_0 = 0.22\) (22%). A new care management program is piloted at a regional hospital. Of the first \(n = 180\) heart failure patients discharged under the new program, 31 were readmitted within 30 days.

(a) The hospital wants to know if the new program has a different readmission rate from the standard. State the null and alternative hypotheses.

(b) Compute the large-sample z test statistic: \[Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}\]

(c) Compute the two-sided p-value and state your conclusion at \(\alpha = 0.05\).

(d) Compute a 95% confidence interval for \(p\) using the Wilson score interval (or the Wald interval). Is \(p_0 = 0.22\) inside the interval? How does this relate to your conclusion in part (c)?

(e) A skeptic notes that \(n = 180\) is not that large and questions whether the Normal approximation is valid. State the common rule-of-thumb for when the large-sample z test for proportions is appropriate, and check it for this problem.
