Problem 1: Two-Sample t-Tests for Means

Part (a) — Welch–Satterthwaite degrees of freedom

Summary statistics:

n1 <- 22; xbar1 <- 412.8; s1 <- 68.4  # COPD
n2 <- 25; xbar2 <- 356.2; s2 <- 41.7  # Controls

# Welch-Satterthwaite
v1 <- s1^2 / n1
v2 <- s2^2 / n2

nu_hat <- (v1 + v2)^2 / (v1^2 / (n1 - 1) + v2^2 / (n2 - 1))
cat(sprintf("v1 = s1^2/n1 = %.4f\n", v1))
v1 = s1^2/n1 = 212.6618
cat(sprintf("v2 = s2^2/n2 = %.4f\n", v2))
v2 = s2^2/n2 = 69.5556
cat(sprintf("Numerator:   (v1 + v2)^2 = %.4f\n", (v1 + v2)^2))
Numerator:   (v1 + v2)^2 = 79646.6711
cat(sprintf("Denominator: %.4f\n", v1^2/(n1-1) + v2^2/(n2-1)))
Denominator: 2355.1563
cat(sprintf("nu_hat = %.2f  -->  round down to %d\n", nu_hat, floor(nu_hat)))
nu_hat = 33.82  -->  round down to 33

\[\hat{\nu} = \frac{(s_1^2/n_1 + s_2^2/n_2)^2}{\dfrac{(s_1^2/n_1)^2}{n_1-1} + \dfrac{(s_2^2/n_2)^2}{n_2-1}}\]

The Welch–Satterthwaite approximation gives \(\hat{\nu} \approx 33.8\), rounded down to \(33\) degrees of freedom.

Part (b) — Welch t-test (one-sided)

SE_diff <- sqrt(s1^2/n1 + s2^2/n2)
t_obs   <- (xbar1 - xbar2) / SE_diff
p_one   <- pt(t_obs, df = nu_hat, lower.tail = FALSE)

cat(sprintf("SE(xbar1 - xbar2) = %.4f\n", SE_diff))
SE(xbar1 - xbar2) = 16.7993
cat(sprintf("t_obs = %.4f\n", t_obs))
t_obs = 3.3692
cat(sprintf("df    = %.2f\n", nu_hat))
df    = 33.82
cat(sprintf("p-value (one-sided, upper) = %.5f\n", p_one))
p-value (one-sided, upper) = 0.00095

Test statistic: \(T_W = \dfrac{412.8 - 356.2}{\sqrt{68.4^2/22 + 41.7^2/25}} = 3.369\)

Degrees of freedom: \(\hat{\nu} \approx 33.8\)

\(p\)-value: \(9.5\times 10^{-4}\)

Conclusion: At \(\alpha = 0.05\) we reject \(H_0\) (\(p < 0.05\)). There is statistically significant evidence that mean plasma fibrinogen is higher in COPD patients than in healthy controls.

Part (c) — 95% two-sided CI

t_crit <- qt(0.975, df = nu_hat)
ci_lo  <- (xbar1 - xbar2) - t_crit * SE_diff
ci_hi  <- (xbar1 - xbar2) + t_crit * SE_diff

cat(sprintf("t_crit (df = %.1f) = %.4f\n", nu_hat, t_crit))
t_crit (df = 33.8) = 2.0326
cat(sprintf("95%% CI: (%.2f, %.2f) mg/dL\n", ci_lo, ci_hi))
95% CI: (22.45, 90.75) mg/dL

Interpretation: We are 95% confident that the true mean plasma fibrinogen is between 22.5 and 90.7 mg/dL higher in COPD patients than in healthy controls. Because the entire interval is positive and excludes zero, the data provide strong evidence of a meaningful difference.

Part (d) — F-test for equality of variances

F_obs  <- s1^2 / s2^2
df1    <- n1 - 1
df2    <- n2 - 1

# Two-sided p-value: 2 * min(lower, upper) tail
p_F <- 2 * min(pf(F_obs, df1, df2), pf(F_obs, df1, df2, lower.tail = FALSE))

cat(sprintf("F = s1^2/s2^2 = %.4f^2 / %.4f^2 = %.4f\n", s1, s2, F_obs))
F = s1^2/s2^2 = 68.4000^2 / 41.7000^2 = 2.6905
cat(sprintf("df1 = %d, df2 = %d\n", df1, df2))
df1 = 21, df2 = 24
cat(sprintf("Two-sided p-value = %.5f\n", p_F))
Two-sided p-value = 0.02115

Hypotheses: \(H_0: \sigma_1^2 = \sigma_2^2\) vs. \(H_a: \sigma_1^2 \neq \sigma_2^2\)

Test statistic: \(F_0 = s_1^2 / s_2^2 = 4678.6 / 1738.9 = 2.691\) on \((21, 24)\) df

\(p\)-value: \(0.0211\)

The \(F\)-test is highly significant, providing strong evidence that the population variances are unequal. The Welch \(t\)-test is therefore the more appropriate choice because it does not assume equal variances. The pooled \(t\)-test would be invalid here.

Part (e) — Pooled t-test for comparison

Sp2 <- ((n1-1)*s1^2 + (n2-1)*s2^2) / (n1 + n2 - 2)
Sp  <- sqrt(Sp2)
SE_pool <- Sp * sqrt(1/n1 + 1/n2)
t_pool  <- (xbar1 - xbar2) / SE_pool
df_pool <- n1 + n2 - 2
p_pool  <- pt(t_pool, df = df_pool, lower.tail = FALSE)
t_crit_pool <- qt(0.975, df = df_pool)
ci_pool <- c((xbar1 - xbar2) - t_crit_pool * SE_pool,
             (xbar1 - xbar2) + t_crit_pool * SE_pool)

cat(sprintf("Sp^2 = %.2f  -->  Sp = %.2f\n", Sp2, Sp))
Sp^2 = 3110.74  -->  Sp = 55.77
cat(sprintf("SE_pool = %.4f\n", SE_pool))
SE_pool = 16.3042
cat(sprintf("t_pool = %.4f, df = %d\n", t_pool, df_pool))
t_pool = 3.4715, df = 45
cat(sprintf("p-value (one-sided) = %.5f\n", p_pool))
p-value (one-sided) = 0.00058
cat(sprintf("95%% Pooled CI: (%.2f, %.2f)\n", ci_pool[1], ci_pool[2]))
95% Pooled CI: (23.76, 89.44)

Comparison:

Method \(t\) df 95% CI \(p\)-value
Welch 3.369 33.8 (22.5, 90.7) 9.5^{-4}
Pooled 3.472 45 (23.8, 89.4) 5.8^{-4}

The two procedures give similar conclusions here because both \(n_1\) and \(n_2\) are moderate. However, the pooled SE is inflated relative to the Welch SE because the larger variance (COPD, \(s_1 = 68.4\)) is averaged with the smaller (Controls, \(s_2 = 41.7\)). When sample sizes are unequal and the larger variance is in the smaller group, the pooled test can be anti-conservative (actual Type I error exceeds nominal \(\alpha\)). The Welch test does not rely on equal-variance assumptions and is generally preferred.

95% CI: (1.4%, 23.4%)

Interpretation: We are 95% confident that the true success rate for Regimen A is between 1.4% and 23.4% higher than for Regimen B. Since the interval contains 0, the data do not provide statistically significant evidence of a difference at the 5% level (though the point estimate favors A).

Part (d) — Pooled vs. unpooled SE: conceptual explanation

When we test \(H_0: p_A = p_B\), we assume under \(H_0\) that there is a single common success probability \(p\). The pooled estimate \(\hat{p}_{\text{pool}} = (x_A + x_B)/(n_A + n_B)\) is the most efficient estimate of this common \(p\) under \(H_0\), so plugging it into the SE is consistent with the null hypothesis and yields a valid test.

For the CI we make no such assumption — the CI must be valid whether or not \(p_A = p_B\). Using the pooled estimate in the CI would distort coverage when \(p_A \neq p_B\) (which is the interesting case we are trying to characterize). The unpooled SE is therefore correct for CI construction.

Part (e) — Relative risk and delta-method CI

RR_hat  <- phatA / phatB
log_RR  <- log(RR_hat)

# Var(log(phat_A/phat_B)) = Var(log phat_A) + Var(log phat_B)
# By delta method: Var(log phat) = (1-p)/(n*p)
var_log_A <- (1 - phatA) / (nA * phatA)
var_log_B <- (1 - phatB) / (nB * phatB)
se_log_RR <- sqrt(var_log_A + var_log_B)

ci_log  <- log_RR + c(-1,1) * z_crit * se_log_RR
ci_RR   <- exp(ci_log)

cat(sprintf("RR = phat_A / phat_B = %.4f / %.4f = %.4f\n",
            phatA, phatB, RR_hat))
RR = phat_A / phat_B = 0.8476 / 0.7238 = 1.1711
cat(sprintf("log(RR) = %.4f,  SE(log RR) = %.5f\n", log_RR, se_log_RR))
log(RR) = 0.1579,  SE(log RR) = 0.07312
cat(sprintf("95%% CI for log(RR): (%.4f, %.4f)\n", ci_log[1], ci_log[2]))
95% CI for log(RR): (0.0146, 0.3012)
cat(sprintf("95%% CI for RR:      (%.4f, %.4f)\n", ci_RR[1],  ci_RR[2]))
95% CI for RR:      (1.0147, 1.3515)

Point estimate: \(\widehat{RR} = 1.171\). Regimen A has an estimated 17.1% higher success rate than Regimen B.

95% CI for RR: (1.015, 1.351). Since this interval includes 1.0, the relative risk is not significantly different from 1 at the 5% level, consistent with the z-test conclusion.

Problem 3: Paired Data Analysis

before <- c(3.8, 5.2, 4.1, 6.7, 3.3, 4.9, 5.8, 7.1, 3.6, 4.4,
            6.0, 5.5, 4.7, 3.9, 5.1)
after  <- c(2.9, 4.4, 3.2, 5.8, 2.8, 4.1, 4.9, 6.0, 2.7, 3.5,
            5.0, 4.6, 3.8, 3.1, 4.3)
d      <- before - after
n_pair <- length(d)

Part (a) — Why paired analysis is appropriate

The same 15 participants are measured twice (before and after the intervention). The two measurements on the same individual are positively correlated — people who start with high HOMA-IR tend to end with high HOMA-IR even after the intervention, reflecting between-subject variation in baseline insulin sensitivity.

If the Welch two-sample test were incorrectly applied, it would treat the 30 observations as independent, ignoring the within-person correlation. This inflates the variance estimate (\(\hat{\sigma}_D^2 = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2 < \sigma_1^2 + \sigma_2^2\) when \(\rho > 0\)), producing wider CIs and larger \(p\)-values — i.e., reduced statistical power to detect a real treatment effect.

Part (b) — Summary statistics of differences

Dbar  <- mean(d)

cat(sprintf("n (pairs)     = %d\n",   n_pair))

\(\bar{D} = 0.8667\), \(S_D = 0.1291\), \(r = 0.9954\).

Variance formula explanation:

Under the correct paired model: \[\text{Var}(D_i) = \sigma_1^2 + \sigma_2^2 - 2\rho\,\sigma_1\,\sigma_2\]

s1_obs <- sd(before)
s2_obs <- sd(after)

var_d_formula <- s1_obs^2 + s2_obs^2 - 2 * r_cor * s1_obs * s2_obs
var_d_direct  <- SD_d^2

cat(sprintf("s_before = %.4f,  s_after = %.4f,  r = %.4f\n",
            s1_obs, s2_obs, r_cor))
s_before = 1.1325,  s_after = 1.0579,  r = 0.9954
cat(sprintf("Var(D) via formula = %.4f\n", var_d_formula))
Var(D) via formula = 0.0167
cat(sprintf("Var(D) direct      = %.4f  (should match)\n", var_d_direct))
Var(D) direct      = 0.0167  (should match)
cat(sprintf("Var(D) if rho = 0  = %.4f  (what unpaired assumes)\n",
            s1_obs^2 + s2_obs^2))
Var(D) if rho = 0  = 2.4018  (what unpaired assumes)

When \(\rho > 0\), \(\sigma_D^2\) is smaller than \(\sigma_1^2 + \sigma_2^2\). The incorrect Welch test uses \(S_1^2/n + S_2^2/n\) as its SE, which overestimates the variance, yielding a wider CI and larger \(p\)-value — in this case failing to detect the significant treatment effect more clearly.

Part (b) — Bootstrap CIs for difference in means

Part (e) — Two-sample permutation test

set.seed(551)
all_obs <- c(platelets_shock, platelets_sepsis)
T_obs   <- mean(platelets_shock) - mean(platelets_sepsis)

perm_stats <- replicate(B, {
  perm <- sample(all_obs)
  mean(perm[1:n1_plt]) - mean(perm[(n1_plt+1):(n1_plt+n2_plt)])
})

p_perm <- mean(abs(perm_stats) >= abs(T_obs))

cat(sprintf("Observed test statistic: %.4f\n", T_obs))
Observed test statistic: -42.7086
cat(sprintf("Permutation p-value (two-sided): %.4f\n", p_perm))
Permutation p-value (two-sided): 0.0684
cat(sprintf("Welch t-test p-value:            %.4f\n", welch_plt$p.value))
Welch t-test p-value:            0.0716

Observed statistic: \(\hat{\Delta} = -42.71\), permutation \(p\)-value: \(0.0684\)

The permutation \(p\)-value and Welch \(t\)-test \(p\)-value agree closely. The permutation test is exactly valid under \(H_0: F_1 = F_2\) (the two populations have the same distribution) — it tests whether the group labels could have been permuted by chance. The Welch \(t\)-test is asymptotically valid under the weaker \(H_0: \mu_1 = \mu_2\).
