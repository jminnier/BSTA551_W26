Lesson 22: Course Review

The Course in One Slide

BSTA 551 is a course in the theory of statistical inference — the mathematical foundations of how we use data to learn about population parameters.

Theme Lessons Core Question
Point Estimation 1–6 What is the best single estimate of \(\theta\)? When is it optimal?
Interval Estimation 7–11 How do we quantify our uncertainty? What guarantees do CIs provide?
Hypothesis Testing 12–17 How do we make decisions? How powerful are those decisions?
Two-Sample Inference 18–20 How do we compare two groups formally?
Nonparametric Inference 21 What can we do without distributional assumptions?

. . .

Connecting thread: Every method in this course is built from the same skeleton — a model, a statistic derived from data, and a distributional argument that tells us how that statistic behaves.

Arc 1: Point Estimation

Bias, Variance, and MSE (Lessons 1–2)

For an estimator \(\hat\theta\) of \(\theta\):

\[\text{MSE}(\hat\theta) = \text{Var}(\hat\theta) + [\text{Bias}(\hat\theta)]^2\]

A sequence of estimators \(\hat\theta_n\) is consistent if \(\hat\theta_n \xrightarrow{P} \theta\) as \(n \to \infty\).

Key examples:

  • \(\bar{X}\): unbiased for \(\mu\); \(\text{Var}(\bar{X}) = \sigma^2/n\); consistent
  • \(S^2 = \frac{1}{n-1}\sum(X_i - \bar{X})^2\): unbiased for \(\sigma^2\); \(\frac{1}{n}\sum(X_i - \bar{X})^2\) is biased (but consistent)
  • MLE of \(\sigma^2\) in \(N(\mu, \sigma^2)\): \(\hat\sigma^2_\text{MLE} = \frac{1}{n}\sum(X_i - \bar{X})^2\) — biased by factor \((n-1)/n\)

Cramér-Rao Lower Bound and Fisher Information (Lesson 3)

Fisher information: \[I(\theta) = E\!\left[\left(\frac{\partial}{\partial\theta}\ln f(X;\theta)\right)^2\right] = -E\!\left[\frac{\partial^2}{\partial\theta^2}\ln f(X;\theta)\right]\]

Cramér-Rao Lower Bound: For any unbiased \(\hat\theta\): \[\text{Var}(\hat\theta) \geq \frac{1}{n\,I(\theta)}\]

An unbiased estimator that achieves the CRLB for all \(\theta\) is the MVUE (minimum variance unbiased estimator). Equivalently, it is a function of a complete sufficient statistic (Lehmann–Scheffé theorem).

. . .

# Fisher information and CRLB for Poisson(lambda)
# f(x; lambda) = e^{-lambda} lambda^x / x!
# d/d(lambda) log f = x/lambda - 1
# I(lambda) = E[(X/lambda - 1)^2] = Var(X)/lambda^2 = lambda/lambda^2 = 1/lambda

fisher_info_pois <- function(lambda) 1 / lambda
lambda_true <- 3
crlb        <- 1 / (20 * fisher_info_pois(lambda_true))

cat(sprintf("CRLB for estimating lambda = %.1f with n = 20:  %.5f\n", lambda_true, crlb))
CRLB for estimating lambda = 3.0 with n = 20:  0.15000
cat(sprintf("Var(Xbar) = lambda/n = %.5f  — achieves CRLB? %s\n",
            lambda_true / 20, isTRUE(all.equal(crlb, lambda_true / 20))))
Var(Xbar) = lambda/n = 0.15000  — achieves CRLB? TRUE

MLE: Properties and Asymptotics (Lesson 4)

The MLE \(\hat\theta_\text{MLE}\) maximizes the log-likelihood \(\ell(\theta) = \sum_{i=1}^n \ln f(x_i; \theta)\).

Key properties under regularity conditions:

  1. Consistent: \(\hat\theta_\text{MLE} \xrightarrow{P} \theta\)
  2. Asymptotically normal: \(\sqrt{n}(\hat\theta_\text{MLE} - \theta) \xrightarrow{d} N\bigl(0,\, [I(\theta)]^{-1}\bigr)\)
  3. Asymptotically efficient: achieves the CRLB as \(n \to \infty\)
  4. Equivariant: \(g(\hat\theta_\text{MLE})\) is the MLE of \(g(\theta)\)

. . .

The asymptotic normality result gives an approximate CI: \[\hat\theta_\text{MLE} \pm z_{\alpha/2} / \sqrt{n\,I(\hat\theta_\text{MLE})}\]

This is the basis of score intervals and the connection between MLE theory and large-sample inference.

Sufficiency (Lessons 5–6)

\(T(X_1, \ldots, X_n)\) is sufficient for \(\theta\) if \(f(x_1, \ldots, x_n; \theta) = h(\mathbf{x})\cdot g(T(\mathbf{x}); \theta)\) (Factorization Theorem).

Sufficiency means \(T\) captures all information in the sample about \(\theta\) — the conditional distribution of \(\mathbf{X} \mid T\) does not depend on \(\theta\).

Rao-Blackwell theorem: If \(\hat\theta\) is unbiased and \(T\) is sufficient, then \(\tilde\theta = E[\hat\theta \mid T]\) satisfies:

\[\text{Var}(\tilde\theta) \leq \text{Var}(\hat\theta), \quad \text{with equality iff } \hat\theta = h(T) \text{ a.s.}\]

Exponential family: \(f(x; \theta) = h(x)\,c(\theta)\exp\!\bigl(\eta(\theta)\,T(x)\bigr)\) — the natural sufficient statistic is \(\sum T(x_i)\).

Arc 2: Interval Estimation

The Pivot Method (Lesson 7)

A pivotal quantity \(Q(X_1, \ldots, X_n, \theta)\) has a distribution that is free of all unknown parameters.

Procedure: Find \(Q\), then solve \(P(a \leq Q \leq b) = 1-\alpha\) for \(\theta\) to obtain the CI.

Key pivots:

Setting Pivot Distribution
\(\mu\), \(\sigma^2\) known \(Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}}\) \(N(0,1)\)
\(\mu\), \(\sigma^2\) unknown \(T = \frac{\bar{X} - \mu}{S/\sqrt{n}}\) \(t_{n-1}\)
\(\sigma^2\), \(\mu\) unknown \(\chi^2 = \frac{(n-1)S^2}{\sigma^2}\) \(\chi^2_{n-1}\)
\(\mu_1 - \mu_2\), \(\sigma\)’s unknown \(T_W = \frac{(\bar{X}_1 - \bar{X}_2) - \Delta}{\sqrt{S_1^2/n_1 + S_2^2/n_2}}\) \(t_{\hat\nu}\) (approx.)

CI Summary: One-Sample and Two-Sample

# One-sample t CI for mu
t.test(x)$conf.int

# One-sample chi-squared CI for sigma^2
n <- length(x); s2 <- var(x)
c(lower = (n-1)*s2 / qchisq(0.975, n-1),
  upper = (n-1)*s2 / qchisq(0.025, n-1))

# One-sample proportion: Wald
p_hat <- mean(x); n <- length(x)
p_hat + c(-1,1) * qnorm(0.975) * sqrt(p_hat*(1-p_hat)/n)

# Wilson score interval (preferred for small n or extreme p)
prop.test(sum(x), length(x), correct = FALSE)$conf.int

# Two-sample Welch t CI
t.test(x1, x2)$conf.int            # default: Welch

# Two-sample proportions CI (unpooled SE)
prop.test(c(y1, y2), c(n1, n2), correct = FALSE)$conf.int

# Two-sample F CI for sigma1^2/sigma2^2
var.test(x1, x2)$conf.int

# Paired t CI
t.test(x1, x2, paired = TRUE)$conf.int

Bootstrap CIs (Lessons 9–10, 20)

The bootstrap approximates the sampling distribution of \(\hat\theta\) without parametric assumptions.

Algorithm: Resample with replacement \(B\) times; compute \(\hat\theta^{*b}\) each time.

Percentile CI: \(\bigl(\hat\theta^*_{(\alpha/2)},\; \hat\theta^*_{(1-\alpha/2)}\bigr)\)

Basic (reflection) CI: \(\bigl(2\hat\theta - \hat\theta^*_{(1-\alpha/2)},\; 2\hat\theta - \hat\theta^*_{(\alpha/2)}\bigr)\)

. . .

For two samples: resample each group separately and independently

For paired data: resample whole pairs \(D_i\) with replacement

When to prefer bootstrap over parametric CIs:

  • Small \(n\) with non-normal or skewed data
  • Parameter is not a mean (median, correlation, quantile)
  • Complex estimator with no known SE formula

Arc 3: Hypothesis Testing

The Framework (Lesson 12)

Term Definition
\(H_0\) Null hypothesis (default claim)
\(H_a\) Alternative hypothesis
Type I error \(\alpha = P(\text{Reject } H_0 \mid H_0 \text{ true})\)
Type II error \(\beta = P(\text{Fail to reject } H_0 \mid H_a \text{ true})\)
Power \(1 - \beta = P(\text{Reject } H_0 \mid H_a \text{ true})\)
p-value \(P(\text{observed or more extreme} \mid H_0)\)

. . .

CI–Test duality (Lesson 7, used throughout): \[\theta_0 \in \text{CI}_{1-\alpha} \;\iff\; \text{fail to reject } H_0: \theta = \theta_0 \text{ at level } \alpha\]

Always report both a p-value and a CI — the CI conveys effect size and precision; the p-value conveys whether \(H_0\) is compatible with the data.

Neyman-Pearson Lemma and LRT (Lessons 15–16)

Neyman-Pearson Lemma: For simple \(H_0: \theta = \theta_0\) vs. \(H_a: \theta = \theta_1\), the most powerful level-\(\alpha\) test rejects when: \[\Lambda = \frac{L(\theta_1; \mathbf{x})}{L(\theta_0; \mathbf{x})} = \frac{\prod f(x_i; \theta_1)}{\prod f(x_i; \theta_0)} > k_\alpha\]

Likelihood Ratio Test (LRT): For composite hypotheses, reject when: \[\lambda(\mathbf{x}) = \frac{\sup_{\theta \in \Theta_0} L(\theta)}{\sup_{\theta \in \Theta} L(\theta)} < c_\alpha\]

Wilks’ theorem: Under \(H_0\) and regularity conditions, \(-2\ln\lambda(\mathbf{X}) \xrightarrow{d} \chi^2_\nu\) where \(\nu = \dim(\Theta) - \dim(\Theta_0)\).

Hypothesis Test Summary

\(H_0\) Test Statistic Null Distribution
\(\mu = \mu_0\) (\(\sigma\) known) \(Z = (\bar{X}-\mu_0)/(\sigma/\sqrt{n})\) \(N(0,1)\)
\(\mu = \mu_0\) (\(\sigma\) unknown) \(T = (\bar{X}-\mu_0)/(S/\sqrt{n})\) \(t_{n-1}\)
\(p = p_0\) \(Z = (\hat{p}-p_0)/\sqrt{p_0(1-p_0)/n}\) \(N(0,1)\)
\(\sigma^2 = \sigma_0^2\) \(\chi^2 = (n-1)S^2/\sigma_0^2\) \(\chi^2_{n-1}\)
\(\mu_1 - \mu_2 = 0\) (Welch) \(T_W = (\bar{X}_1-\bar{X}_2)/\sqrt{S_1^2/n_1+S_2^2/n_2}\) \(t_{\hat\nu}\)
\(p_1 = p_2\) \(Z = (\hat{p}_1-\hat{p}_2)/\text{SE}_\text{pool}\) \(N(0,1)\)
\(\sigma_1^2 = \sigma_2^2\) \(F = S_1^2/S_2^2\) \(F_{n_1-1,n_2-1}\)
\(\mu_D = 0\) (paired) \(T = \bar{D}/(S_D/\sqrt{n})\) \(t_{n-1}\)

Two-Sample Inference Map (Lessons 18–21)

Welch vs. Pooled: When Does It Matter?

Code 
set.seed(551)
B_sim <- 3000

sim_t1_error <- function(n1, n2, sigma1, sigma2) {
  replicate(B_sim, {
    x1 <- rnorm(n1, 0, sigma1)
    x2 <- rnorm(n2, 0, sigma2)
    c(Welch  = t.test(x1, x2, var.equal = FALSE)$p.value,
      Pooled = t.test(x1, x2, var.equal = TRUE)$p.value)
  }) |> t() |> as_tibble() |>
    summarise(across(everything(), \(x) mean(x < 0.05))) |>
    mutate(n1 = n1, n2 = n2, sigma1 = sigma1, sigma2 = sigma2,
           scenario = sprintf("n=(%d,%d)\nsd=(%.0f,%.0f)", n1,n2,sigma1,sigma2))
}

scenarios <- list(
  list(n1=20, n2=20, s1=5,  s2=5),
  list(n1=20, n2=20, s1=5,  s2=15),
  list(n1=10, n2=30, s1=5,  s2=15),  # larger group has larger sd -> conservative
  list(n1=30, n2=10, s1=5,  s2=15)   # larger group has smaller sd -> anti-conservative
)

results_t <- map_dfr(scenarios, function(s) {
  sim_t1_error(s$n1, s$n2, s$s1, s$s2)
})

results_t |>
  pivot_longer(c(Welch, Pooled), names_to = "Test", values_to = "TypeI") |>
  ggplot(aes(x = scenario, y = TypeI, fill = Test)) +
  geom_col(position = "dodge", width = 0.55) +
  geom_hline(yintercept = 0.05, linetype = "dashed", linewidth = 1.1) +
  scale_fill_manual(values = c("Welch" = "#006a4e", "Pooled" = "#e74c3c")) +
  scale_y_continuous(labels = scales::percent, limits = c(0, 0.22)) +
  labs(
    title    = "Type I Error: Welch vs. Pooled t-test Under H\u2080 (equal means)",
    subtitle = "Pooled t-test inflates Type I error when variances are unequal AND n's are unequal with larger group having smaller sd",
    x = "Scenario", y = "Type I Error Rate", fill = NULL
  ) +
  theme(legend.position = "bottom",
        axis.text.x = element_text(size = 10))

Nonparametric Test Summary (Lesson 21)

Test Statistic R function Null distribution
Sign test \(S^+ = \#\{D_i > 0\}\) pbinom(s, n*, 0.5) \(\text{Bin}(n^*, 1/2)\)
Wilcoxon signed-rank \(W^+ = \sum_{\{D_i>0\}} R_i\) wilcox.test(x, y, paired=TRUE) Exact / normal approx
Wilcoxon rank-sum \(W = \sum_{\text{grp 1}} R_i\) wilcox.test(x, y) Exact / normal approx

ARE at normality (relative to corresponding parametric test):

  • Signed-rank vs. \(t\): \(3/\pi \approx 0.955\) — minimal loss, sometimes large gains
  • Sign vs. \(t\): \(2/\pi \approx 0.637\) — notable loss at normality, but gains for heavy tails
  • Rank-sum vs. Welch \(t\): \(3/\pi \approx 0.955\) — same as signed-rank

Method Selection and Complete Example

Decision Guide

Step 1 — What parameter am I estimating / testing? \(\mu\), \(\sigma^2\), \(p\), \(\mu_1 - \mu_2\), \(\mu_D\), \(p_1 - p_2\), median, …

Step 2 — What is the study design? One sample / Two independent samples / Paired

Step 3 — What distributional assumptions are reasonable? Normal? Large \(n\) (CLT)? Heavy-tailed/skewed? Ordinal only?

Step 4 — What is the goal? Point estimate / CI / Hypothesis test / All three?

. . .

ImportantThree Rules of Thumb
  1. Default for two independent groups: Welch \(t\)-test (not pooled). Use pooled only with strong prior evidence of equal variances and balanced \(n\)
  2. Default for paired non-normal data with small \(n\): Wilcoxon signed-rank test
  3. Always report a CI alongside your p-value — the CI conveys magnitude and precision

Key Formulas Reference

Point Estimation Formulas

Fisher information: \[I(\theta) = E\!\left[\!\left(\frac{\partial \ln f}{\partial\theta}\right)^{\!2}\right] = -E\!\left[\frac{\partial^2 \ln f}{\partial\theta^2}\right]\]

CRLB: \(\text{Var}(\hat\theta) \geq [n\,I(\theta)]^{-1}\) for any unbiased \(\hat\theta\)

MLE asymptotics: \(\sqrt{n}(\hat\theta_\text{MLE} - \theta) \xrightarrow{d} N\bigl(0,\,[I(\theta)]^{-1}\bigr)\)

Rao-Blackwell: \(\tilde\theta = E[\hat\theta \mid T] \Rightarrow \text{Var}(\tilde\theta) \leq \text{Var}(\hat\theta)\)

Interval Estimation Formulas

Welch-Satterthwaite df: \[\hat\nu = \frac{(S_1^2/n_1 + S_2^2/n_2)^2}{(S_1^2/n_1)^2/(n_1-1) + (S_2^2/n_2)^2/(n_2-1)}\]

Variance of paired differences: \[\sigma_D^2 = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2\]

CI width ratio (paired/unpaired, \(\sigma_1 = \sigma_2\)): \(\sqrt{1 - \rho}\)

Bootstrap percentile CI: \(\bigl(\hat\theta^*_{(\alpha/2)},\; \hat\theta^*_{(1-\alpha/2)}\bigr)\)

Hypothesis Testing Formulas

NP Lemma rejection region: \(\Lambda = L(\theta_1)/L(\theta_0) > k_\alpha\)

Wilks’ theorem: \(-2\ln\lambda(\mathbf{X}) \xrightarrow{d} \chi^2_{\dim(\Theta) - \dim(\Theta_0)}\) under \(H_0\)

Power: \(1 - \beta(\theta') = P\bigl(T(\mathbf{X}) \in C \mid \theta = \theta'\bigr)\) for \(\theta' \in \Theta_a\)

CI–test duality: \(\theta_0 \in \text{CI}_{1-\alpha} \iff\) fail to reject \(H_0: \theta = \theta_0\) at level \(\alpha\)

Nonparametric Formulas

Sign test: \(S^+ = \#\{D_i > 0\} \sim \text{Bin}(n^*, 1/2)\) under \(H_0\)

Wilcoxon signed-rank: \[E[W^+] = \frac{n^*(n^*+1)}{4}, \quad \text{Var}(W^+) = \frac{n^*(n^*+1)(2n^*+1)}{24}\]

Wilcoxon rank-sum: \[E[W] = \frac{n_1(N+1)}{2}, \quad \text{Var}(W) = \frac{n_1 n_2(N+1)}{12}\]

ARE (signed-rank vs. \(t\), normal data): \(3/\pi \approx 0.955\)

Final Exam Guidance

The take-home final exam spans the full course. You should be able to:

Theoretical problems:

  • Derive the MLE and assess whether it achieves the CRLB
  • Apply the factorization theorem to identify a sufficient statistic
  • Apply the Neyman-Pearson Lemma to derive the UMP test for simple hypotheses
