Lesson 7: From Point Estimates to Intervals

Review: What We’ve Learned About Estimation

Point Estimation (Lessons 1-6):

  • Estimators: statistics that estimate parameters
  • Properties: bias, variance, MSE, efficiency
  • Construction: Method of Moments, Maximum Likelihood
  • Quality: MVUE, sufficient statistics, Cramér-Rao bound

The Limitation of Point Estimates:

A single number (\(\hat{\theta} = 0.75\)) tells us nothing about precision or uncertainty.

Today’s Goals

  1. Understand why we need interval estimates
  2. Derive confidence intervals using pivotal quantities
  3. Construct and interpret z-intervals (known \(\sigma\))
  4. Construct and interpret t-intervals (unknown \(\sigma\))
  5. Understand confidence intervals for proportions
  6. Apply these methods to medical research examples

Motivating Example: Clinical Trial

A new antihypertensive drug is tested in \(n = 36\) patients. The mean reduction in systolic blood pressure is \(\bar{x} = 12.3\) mmHg.

Point estimate: \(\hat{\mu} = 12.3\) mmHg

Questions we can’t answer with just the point estimate:

  • How close is 12.3 to the true mean reduction?
  • Is the true mean likely to be at least 10 mmHg?
  • How much could \(\bar{X}\) vary in repeated trials?

The Solution

A confidence interval provides a range of plausible values for the parameter, along with a measure of confidence.

The Fundamental Idea

From Point to Interval

Key insight: The interval captures our uncertainty about the true parameter value.

What Is a Confidence Interval?

Definition: Confidence Interval

A confidence interval (CI) for a parameter \(\theta\) is a random interval \((L, U)\) computed from sample data such that: \[P(L < \theta < U) = 1 - \alpha\] for a specified confidence level \(1 - \alpha\).

Important:

  • \(L\) and \(U\) are random (they depend on the sample)
  • \(\theta\) is fixed (but unknown)
  • The probability statement is about the procedure, not about \(\theta\)

Correct Interpretation of Confidence Intervals

Common Misconception

“There is a 95% probability that \(\mu\) lies in the interval (7.4, 17.2).”

This is WRONG! After computing the interval, \(\mu\) either is or is not in the interval. There’s no probability involved.

Correct Interpretation

“If we repeated this procedure many times, 95% of the resulting intervals would contain the true \(\mu\).”

Or more simply: “We are 95% confident that the true mean lies between 7.4 and 17.2.”

Visualizing Confidence Level: Simulation

# Simulate 100 confidence intervals
set.seed(551)
true_mu <- 10; sigma <- 4; n <- 25

ci_data <- tibble(sample_id = 1:100) |>
  rowwise() |>
  mutate(
    xbar = mean(rnorm(n, true_mu, sigma)),
    lower = xbar - 1.96 * sigma / sqrt(n),
    upper = xbar + 1.96 * sigma / sqrt(n),
    contains_mu = lower < true_mu & upper > true_mu
  )

# Count how many contain the true mean
sum(ci_data$contains_mu)
[1] 94

Pivotal Quantities

The Key to Constructing CIs

Definition: Pivotal Quantity

A pivotal quantity is a function \(h(X_1, \ldots, X_n; \theta)\) of the data and parameter such that:

  1. It depends on both the sample and \(\theta\)
  2. Its distribution does not depend on \(\theta\) (or any other unknown parameters)

Why pivotal quantities matter:

  • We can find critical values that don’t depend on unknowns
  • We can “solve for \(\theta\)” to get confidence limits

Example: The Standard Pivotal Quantity

Let \(X_1, \ldots, X_n \stackrel{iid}{\sim} N(\mu, \sigma^2)\) with \(\sigma\) known.

Consider: \[Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}}\]

Check the properties:

  1. \(Z\) depends on \(\bar{X}\) (data) and \(\mu\) (parameter) ✓
  2. \(Z \sim N(0, 1)\) — the distribution doesn’t depend on \(\mu\) ✓

\(Z\) is a pivotal quantity!

From Pivotal Quantity to CI

Since \(Z \sim N(0, 1)\), we know: \[P(-z_{\alpha/2} < Z < z_{\alpha/2}) = 1 - \alpha\]

Substitute \(Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}}\): \[P\left(-z_{\alpha/2} < \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} < z_{\alpha/2}\right) = 1 - \alpha\]

Solve for \(\mu\): \[P\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}} < \mu < \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right) = 1 - \alpha\]

This gives us the confidence interval formula!

CI for Mean: \(\sigma\) Known

The Z-Interval

Z Confidence Interval for Normal Mean (\(\sigma\) Known)

If \(X_1, \ldots, X_n \sim N(\mu, \sigma^2)\) with \(\sigma\) known, a \(100(1-\alpha)\%\) CI for \(\mu\) is: \[\bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}\] where \(z_{\alpha/2}\) is the critical value with \(P(Z > z_{\alpha/2}) = \alpha/2\).

Common critical values:

Confidence Level \(\alpha\) \(\alpha/2\) \(z_{\alpha/2}\)
90% 0.10 0.05 1.645
95% 0.05 0.025 1.960
99% 0.01 0.005 2.576

Example: Tensile Strength (Devore Example 8.1)

Synthetic fibers are tested for tensile strength. From past data, \(\sigma = 55\) MPa is known. A sample of \(n = 31\) fibers has \(\bar{x} = 1064\) MPa.

95% Confidence Interval:

xbar <- 1064
sigma <- 55
n <- 31
alpha <- 0.05

z_crit <- qnorm(1 - alpha/2)
margin <- z_crit * sigma / sqrt(n)

c(xbar - margin, xbar + margin)
[1] 1044.639 1083.361

Interpretation: We are 95% confident that the true mean tensile strength is between 1044.6 and 1083.4 MPa.

Medical Example: Blood Glucose Levels

A hospital monitors fasting blood glucose in diabetic patients. Historical data shows \(\sigma = 18\) mg/dL. A sample of \(n = 40\) patients has \(\bar{x} = 142\) mg/dL.

Construct a 99% CI for the population mean glucose level:

xbar <- 142
sigma <- 18
n <- 40
alpha <- 0.01

z_crit <- qnorm(1 - alpha/2)
cat("z critical value:", round(z_crit, 3), "\n")
z critical value: 2.576 
margin <- z_crit * sigma / sqrt(n)
cat("Margin of error:", round(margin, 2), "mg/dL\n")
Margin of error: 7.33 mg/dL
cat("99% CI: (", round(xbar - margin, 1), ",", round(xbar + margin, 1), ")")
99% CI: ( 134.7 , 149.3 )

Clinical interpretation: We can be 99% confident that the true mean fasting glucose for this patient population is between 134.7 and 149.3 mg/dL.

Anatomy of a Confidence Interval

\[\bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}\]

Three factors affect the margin of error:

  1. Confidence level (\(z_{\alpha/2}\)): Higher confidence → wider interval
  2. Population variability (\(\sigma\)): More variation → wider interval
  3. Sample size (\(n\)): Larger sample → narrower interval

Interactive: Effect of Confidence Level

# Same data, different confidence levels
xbar <- 1064; sigma <- 55; n <- 31

confidence_levels <- c(0.90, 0.95, 0.99)

tibble(conf_level = confidence_levels) |>
  mutate(
    z_crit = qnorm(1 - (1 - conf_level)/2),
    margin = z_crit * sigma / sqrt(n),
    lower = xbar - margin,
    upper = xbar + margin,
    width = upper - lower
  )
# A tibble: 3 × 6
  conf_level z_crit margin lower upper width
       <dbl>  <dbl>  <dbl> <dbl> <dbl> <dbl>
1       0.9    1.64   16.2 1048. 1080.  32.5
2       0.95   1.96   19.4 1045. 1083.  38.7
3       0.99   2.58   25.4 1039. 1089.  50.9

Takeaway: Higher confidence requires wider intervals!

Sample Size Determination

Question: How large should \(n\) be to achieve a desired precision?

If we want the margin of error to be at most \(b\): \[z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} \leq b\]

Solving for \(n\): \[n \geq \left(\frac{z_{\alpha/2} \cdot \sigma}{b}\right)^2\]

Sample Size Example: Clinical Trial Design

A pharmaceutical company wants to estimate mean drug clearance time. From pilot data, \(\sigma \approx 25\) minutes. They want a 95% CI with margin of error ≤ 5 minutes.

sigma <- 25
b <- 5  # desired margin of error
alpha <- 0.05
z_crit <- qnorm(1 - alpha/2)

n_required <- (z_crit * sigma / b)^2
cat("Required sample size:", ceiling(n_required))
Required sample size: 97

Note: Always round up to ensure the desired precision!

One-Sided Confidence Bounds

Sometimes we only care about one direction:

  • Lower bound: We want to know the minimum plausible value
  • Upper bound: We want to know the maximum plausible value

One-Sided Bounds

Lower Confidence Bound: \(\bar{x} - z_{\alpha} \cdot \frac{\sigma}{\sqrt{n}} < \mu\)

Upper Confidence Bound: \(\mu < \bar{x} + z_{\alpha} \cdot \frac{\sigma}{\sqrt{n}}\)

Note: Use \(z_\alpha\) (not \(z_{\alpha/2}\)) for one-sided bounds at confidence level \(1 - \alpha\).

Medical Example: Drug Half-Life

A pharmacologist measures half-life of a new drug. With \(n = 20\) subjects, \(\bar{x} = 4.2\) hours, and known \(\sigma = 0.8\) hours.

Find a 95% lower confidence bound:

xbar <- 4.2
sigma <- 0.8
n <- 20
alpha <- 0.05

z_crit <- qnorm(1 - alpha)  # Note: z_alpha, not z_alpha/2
lower_bound <- xbar - z_crit * sigma / sqrt(n)

cat("95% lower confidence bound:", round(lower_bound, 2), "hours\n")
95% lower confidence bound: 3.91 hours
cat("Interpretation: We are 95% confident that the true half-life",
    "\nis at least", round(lower_bound, 2), "hours")
Interpretation: We are 95% confident that the true half-life 
is at least 3.91 hours

CI for Mean: \(\sigma\) Unknown

The Realistic Case

In practice, we rarely know the population standard deviation \(\sigma\).

Natural idea: Replace \(\sigma\) with the sample standard deviation \(s\).

But what happens to our pivotal quantity?

\[Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)\]

becomes

\[T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim \; ???\]

The t Distribution

The t distribution has heavier tails than the normal — accounting for extra uncertainty from estimating \(\sigma\).

Student’s t Distribution

Gosset’s Theorem

If \(X_1, \ldots, X_n \stackrel{iid}{\sim} N(\mu, \sigma^2)\), then: \[T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t_{n-1}\] where \(t_{n-1}\) denotes the t distribution with \(n-1\) degrees of freedom.

Key properties of \(t_\nu\):

  • Symmetric around 0
  • Heavier tails than \(N(0, 1)\)
  • As \(\nu \to \infty\), \(t_\nu \to N(0, 1)\)

Why \((n-1)\) Degrees of Freedom?

The sample variance involves: \[S^2 = \frac{1}{n-1}\sum_{i=1}^n(X_i - \bar{X})^2\]

Since \(\sum(X_i - \bar{X}) = 0\), knowing any \(n-1\) deviations determines the last one.

Intuition: We “use up” one degree of freedom by estimating \(\mu\) with \(\bar{X}\).

The One-Sample t Interval

t Confidence Interval for Normal Mean (\(\sigma\) Unknown)

If \(X_1, \ldots, X_n \sim N(\mu, \sigma^2)\), a \(100(1-\alpha)\%\) CI for \(\mu\) is: \[\bar{x} \pm t_{\alpha/2, n-1} \cdot \frac{s}{\sqrt{n}}\] where \(t_{\alpha/2, n-1}\) is the critical value with \(P(T > t_{\alpha/2, n-1}) = \alpha/2\) for \(T \sim t_{n-1}\).

The quantity \(s/\sqrt{n}\) is called the standard error of the mean (SEM or SE).

t Critical Values

# Compare z and t critical values for 95% CI
z_crit <- qnorm(0.975)

df_values <- c(5, 10, 20, 30, 50, 100, Inf)

tibble(
  df = c("5", "10", "20", "30", "50", "100", "∞ (z)"),
  t_critical = round(c(head(t_crits, -1), z_crit), 3)
)
# A tibble: 7 × 2

Confidence Intervals for Proportions

The Setup

Situation: We observe \(X\) successes in \(n\) independent Bernoulli trials.

  • \(X \sim \text{Binomial}(n, p)\)
  • Point estimate: \(\hat{p} = X/n\)

Examples:

  • Proportion of patients responding to treatment
  • Proportion of adverse events
  • Disease prevalence in a population

The Wald Interval (Traditional)

For large \(n\), \(\hat{P} = X/n\) is approximately normal: \[\hat{P} \approx N\left(p, \frac{p(1-p)}{n}\right)\]

The Wald (traditional) 95% CI: \[\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\]

Problems with the Wald Interval

  • Poor coverage probability for \(p\) near 0 or 1
  • Can produce bounds outside [0, 1]
  • Not recommended for small samples

Coverage Problems with Wald

The Wald interval often has coverage below the nominal level!

The Score (Wilson) Interval

A better approach: solve for \(p\) in the pivotal quantity directly.

Score Confidence Interval for a Proportion

\[\frac{\hat{p} + \frac{z_{\alpha/2}^2}{2n} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z_{\alpha/2}^2}{4n^2}}}{1 + \frac{z_{\alpha/2}^2}{n}}\]

Advantages:

  • Coverage probability much closer to nominal level
  • Handles extreme proportions well
  • Always produces bounds in [0, 1]

The Agresti-Coull Interval

A simpler approximation that works well in practice:

Agresti-Coull (“Add Two Successes and Two Failures”)

Let \(\tilde{n} = n + 4\) and \(\tilde{p} = \frac{X + 2}{n + 4}\)

Then use: \[\tilde{p} \pm z_{\alpha/2}\sqrt{\frac{\tilde{p}(1-\tilde{p})}{\tilde{n}}}\]

Why it works: Adding 2 successes and 2 failures “shrinks” extreme estimates toward 0.5.

Comparing Intervals: Clinical Trial Example

In a Phase II trial, 23 of 40 patients respond to treatment.

x <- 23; n <- 40; p_hat <- x/n
cat("Sample proportion:", p_hat, "\n\n")
Sample proportion: 0.575 
# Wald interval
se_wald <- sqrt(p_hat * (1 - p_hat) / n)
wald_ci <- p_hat + c(-1, 1) * 1.96 * se_wald

# Agresti-Coull interval
n_tilde <- n + 4
p_tilde <- (x + 2) / n_tilde
se_ac <- sqrt(p_tilde * (1 - p_tilde) / n_tilde)
ac_ci <- p_tilde + c(-1, 1) * 1.96 * se_ac

cat("Wald 95% CI:          (", round(wald_ci[1], 3), ",", round(wald_ci[2], 3), ")\n")
Wald 95% CI:          ( 0.422 , 0.728 )
cat("Agresti-Coull 95% CI: (", round(ac_ci[1], 3), ",", round(ac_ci[2], 3), ")")
Agresti-Coull 95% CI: ( 0.422 , 0.715 )

Medical Example: Adverse Event Rate

In a safety study, 8 out of 200 patients experience a serious adverse event.

x <- 8; n <- 200

# Score interval
result <- prop.test(x, n, conf.level = 0.95, correct = FALSE)
cat("Point estimate:", x/n, "\n")
Point estimate: 0.04 
cat("95% Score CI:", round(result$conf.int, 4))
95% Score CI: 0.0204 0.0769

Clinical interpretation: We are 95% confident that the true rate of serious adverse events is between 1.8% and 7.7%.

Sample Size for Proportions

To achieve a margin of error \(b\) with confidence level \(1 - \alpha\):

\[n = \frac{z_{\alpha/2}^2 \cdot p(1-p)}{b^2}\]

Problem: We don’t know \(p\) before the study!

Conservative approach: Use \(p = 0.5\) (maximizes \(p(1-p)\)): \[n = \frac{z_{\alpha/2}^2 \cdot 0.25}{b^2}\]

Sample Size Example: Disease Prevalence

An epidemiologist wants to estimate disease prevalence with a margin of error ≤ 3% with 95% confidence.

b <- 0.03  # margin of error
z <- qnorm(0.975)

# Conservative (p = 0.5)
n_conservative <- z^2 * 0.25 / b^2
cat("Conservative sample size:", ceiling(n_conservative), "\n")
Conservative sample size: 1068 
# If we believe p ≈ 0.10
n_informed <- z^2 * 0.10 * 0.90 / b^2
cat("Informed sample size (p ≈ 0.10):", ceiling(n_informed))
Informed sample size (p ≈ 0.10): 385

Summary: CI Methods Comparison

Method When to Use Notes
Z-interval Normal data, \(\sigma\) known Rarely applicable
t-interval Normal data, \(\sigma\) unknown Check normality
Wald (proportion) Large \(n\), \(p\) not extreme Poor coverage
Score/Wilson General Best for proportions
Agresti-Coull Quick calculation Good approximation

Interpreting CIs in Practice

What CIs Tell Us

Valid Interpretations

  • “We are 95% confident that \(\mu\) lies between L and U”
  • “The interval (L, U) is a plausible range for \(\mu\)”
  • “In repeated sampling, 95% of such intervals would contain \(\mu\)”

Invalid Interpretations

  • “There is a 95% probability that \(\mu\) is in (L, U)” ✗
  • “95% of the data falls between L and U” ✗
  • “The true mean varies between L and U” ✗

Common Mistakes in Medical Literature

Mistake Correct Interpretation
The probability that the true effect is in the CI is 95% We are 95% confident the true effect is in the CI
95% of patients have values in this range We are 95% confident the mean is in this range
If we repeat the study, results will be in the CI 95% of future CIs would contain the true mean

Clinical Decision Making

Example: A drug reduces blood pressure by an estimated 12 mmHg with 95% CI (8, 16).

Questions we can answer:

  • Is the effect clinically meaningful? (If minimum important difference is 5 mmHg, yes!)
  • Is zero a plausible value? (No — CI excludes 0)
  • What’s the worst-case scenario? (Lower bound suggests at least 8 mmHg effect)

Relationship to Hypothesis Testing

Preview of Coming Material

A 95% CI contains all parameter values that would not be rejected by a two-sided test at \(\alpha = 0.05\).

  • If CI excludes the null value → reject \(H_0\)
  • If CI includes the null value → fail to reject \(H_0\)

Example: 95% CI for mean difference is (8, 16).

  • Test \(H_0: \mu = 0\) → Reject (0 not in CI)
  • Test \(H_0: \mu = 10\) → Fail to reject (10 in CI)

Summary and Looking Ahead

Lesson 7 Summary

Key Concepts:

  1. Confidence Intervals provide a range of plausible values with quantified uncertainty

  2. Pivotal Quantities allow us to construct CIs without knowing unknown parameters

  3. Z-intervals (\(\sigma\) known): \(\bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\)

  4. t-intervals (\(\sigma\) unknown): \(\bar{x} \pm t_{\alpha/2, n-1}\frac{s}{\sqrt{n}}\)

  5. Proportion intervals: Score/Wilson preferred over Wald

Key Formulas

Parameter CI Formula Conditions
\(\mu\) (\(\sigma\) known) \(\bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\) Normal data
\(\mu\) (\(\sigma\) unknown) \(\bar{x} \pm t_{\alpha/2, n-1}\frac{s}{\sqrt{n}}\) Normal data
\(p\) (Wald) \(\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\) Large \(n\)
\(p\) (Agresti-Coull) \(\tilde{p} \pm z_{\alpha/2}\sqrt{\frac{\tilde{p}(1-\tilde{p})}{\tilde{n}}}\) General
