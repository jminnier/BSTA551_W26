Motivating Example

A clinical trial randomizes \(n_1 = 45\) patients to a new antihypertensive drug and \(n_2 = 43\) to placebo. After 12 weeks, we measure the reduction in systolic blood pressure (mmHg). Does the drug produce a larger mean reduction than placebo?

We need two-sample methods because the groups are independent.

Two-Sample Setup and Point Estimation

The Two-Sample Model

Setup: Two independent random samples from possibly different populations:

\[X_{11}, X_{12}, \ldots, X_{1n_1} \stackrel{iid}{\sim} F_1 \quad \text{with mean } \mu_1, \text{ variance } \sigma_1^2\]

\[X_{21}, X_{22}, \ldots, X_{2n_2} \stackrel{iid}{\sim} F_2 \quad \text{with mean } \mu_2, \text{ variance } \sigma_2^2\]

The two samples are independent of each other.

Parameter of interest: \(\Delta = \mu_1 - \mu_2\)

Point estimator: \(\hat{\Delta} = \bar{X}_1 - \bar{X}_2\)

Properties of \(\hat{\Delta}\):

  • \(E[\bar{X}_1 - \bar{X}_2] = \mu_1 - \mu_2\) \(\Rightarrow\) unbiased
  • \(\text{Var}(\bar{X}_1 - \bar{X}_2) = \dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}\) (by independence)
  • SE\((\bar{X}_1 - \bar{X}_2) = \sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}\)

Sampling Distribution of \(\bar{X}_1 - \bar{X}_2\)

Case 1: Both populations normal (any sample size): \[\bar{X}_1 - \bar{X}_2 \sim N\!\left(\mu_1 - \mu_2,\; \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}\right)\]

Case 2: Non-normal populations, large samples (CLT): \[\bar{X}_1 - \bar{X}_2 \;\dot{\sim}\; N\!\left(\mu_1 - \mu_2,\; \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}\right)\]

In either case, the standardized statistic is approximately \(N(0,1)\):

\[Z = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1 - \mu_2)}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}} \;\sim\; N(0,1)\]

This is a pivotal quantity when \(\sigma_1^2\) and \(\sigma_2^2\) are known.

Case 1: Variances Known (z-procedures)

Two-Sample z-Interval (DBC 9.5)

When \(\sigma_1^2\) and \(\sigma_2^2\) are known, the pivot \(Z\) gives a \(100(1-\alpha)\%\) CI for \(\mu_1 - \mu_2\):

\[(\bar{X}_1 - \bar{X}_2) \pm z_{\alpha/2} \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}\]

Two-sample z-test of \(H_0: \mu_1 - \mu_2 = \Delta_0\):

\[Z = \frac{(\bar{X}_1 - \bar{X}_2) - \Delta_0}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}}\]

Reject \(H_0\) at level \(\alpha\):

Alternative Rejection Region
\(\mu_1 - \mu_2 > \Delta_0\) \(Z > z_\alpha\)
\(\mu_1 - \mu_2 < \Delta_0\) \(Z < -z_\alpha\)
\(\mu_1 - \mu_2 \neq \Delta_0\) \(|Z| > z_{\alpha/2}\)

Medical Example: Two-Sample z-Test

Study: A pilot study compares mean serum cortisol (μg/dL) between ICU patients with sepsis (\(n_1 = 30\), known \(\sigma_1 = 6\)) and non-septic ICU controls (\(n_2 = 35\), known \(\sigma_2 = 5\)). Observed: \(\bar{x}_1 = 28.4\), \(\bar{x}_2 = 22.1\). Test \(H_0: \mu_1 = \mu_2\) vs. \(H_a: \mu_1 > \mu_2\) at \(\alpha = 0.05\).

# Summary statistics
xbar1 <- 28.4; xbar2 <- 22.1
sigma1 <- 6;   sigma2 <- 5
n1 <- 30;      n2 <- 35
alpha <- 0.05

# Test statistic and p-value (one-sided)
se_diff <- sqrt(sigma1^2/n1 + sigma2^2/n2)
z_obs   <- (xbar1 - xbar2) / se_diff
p_value <- pnorm(z_obs, lower.tail = FALSE)

# 95% CI (two-sided)
z_crit <- qnorm(1 - alpha/2)
ci_lo  <- (xbar1 - xbar2) - z_crit * se_diff
ci_hi  <- (xbar1 - xbar2) + z_crit * se_diff

cat("SE of difference:", round(se_diff, 3), "\n")
SE of difference: 1.384 
cat("Z statistic:", round(z_obs, 3), "\n")
Z statistic: 4.553 
cat("One-sided p-value:", round(p_value, 5), "\n")
One-sided p-value: 0 
cat("95% CI for mu1 - mu2: (", round(ci_lo, 2), ",", round(ci_hi, 2), ")\n")
95% CI for mu1 - mu2: ( 3.59 , 9.01 )

Conclusion: \(Z = 4.55\), \(p < 0.001\). Strong evidence that septic ICU patients have higher mean cortisol.

Case 2: Variances Unknown

The Challenge: Unknown Variances

In practice, \(\sigma_1^2\) and \(\sigma_2^2\) are rarely known. We estimate them from the data:

\[S_1^2 = \frac{1}{n_1-1}\sum_{j=1}^{n_1}(X_{1j}-\bar{X}_1)^2, \quad S_2^2 = \frac{1}{n_2-1}\sum_{j=1}^{n_2}(X_{2j}-\bar{X}_2)^2\]

The standardized statistic \[T = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1-\mu_2)}{\sqrt{S_1^2/n_1 + S_2^2/n_2}}\]

does not follow an exact \(t\) distribution (Behrens-Fisher problem).

Two approaches:

  1. Welch (Satterthwaite) approximation: \(T\) is approximately \(t_\nu\) with estimated df \(\hat\nu\)
  2. Pooled t-test: assume \(\sigma_1^2 = \sigma_2^2\), use exact \(t_{n_1+n_2-2}\) distribution

Welch’s t-Test (DBC 9.5) — Recommended Default

Welch’s t-statistic: \[T_W = \frac{(\bar{X}_1 - \bar{X}_2) - \Delta_0}{\sqrt{S_1^2/n_1 + S_2^2/n_2}}\]

Under \(H_0\), \(T_W \approx t_{\hat\nu}\) where the Welch-Satterthwaite degrees of freedom are:

\[\hat\nu = \frac{(S_1^2/n_1 + S_2^2/n_2)^2}{\dfrac{(S_1^2/n_1)^2}{n_1-1} + \dfrac{(S_2^2/n_2)^2}{n_2-1}}\]

Welch 95% CI for \(\mu_1 - \mu_2\): \[(\bar{X}_1 - \bar{X}_2) \pm t_{\alpha/2,\,\hat\nu}\,\sqrt{\frac{S_1^2}{n_1} + \frac{S_2^2}{n_2}}\]

Why Welch?

The Welch test is robust to unequal variances and performs well even when \(\sigma_1^2 = \sigma_2^2\). It is the default in R’s t.test() and is recommended by most statisticians.

The Pooled t-Test (DBC 9.5)

When \(\sigma_1^2 = \sigma_2^2 = \sigma^2\) (equal variances), we pool information:

\[S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2} \quad \text{(pooled variance estimator)}\]

Pooled t-statistic: \[T_P = \frac{(\bar{X}_1 - \bar{X}_2) - \Delta_0}{S_p\sqrt{1/n_1 + 1/n_2}} \sim t_{n_1+n_2-2} \quad \text{(exact, under normality + equal } \sigma^2\text{)}\]

Pooled 95% CI: \[(\bar{X}_1 - \bar{X}_2) \pm t_{\alpha/2,\,n_1+n_2-2}\;S_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}\]

When to Use Pooled t

Only use the pooled t when there is strong prior reason to believe \(\sigma_1^2 = \sigma_2^2\) (e.g., same measurement in similar populations). Do not use an F-test on the same data to justify pooling — this inflates Type I error.

Welch vs. Pooled: Comparison

Code 
set.seed(551)
# Simulate 10,000 two-sample experiments under H0
# Compare Type I error when sigma1 != sigma2
sim_ttest <- function(n1, n2, sigma1, sigma2, B = 10000) {
  map_dfr(1:B, function(i) {
    x1 <- rnorm(n1, mean = 0, sd = sigma1)
    x2 <- rnorm(n2, mean = 0, sd = sigma2)
    p_welch  <- t.test(x1, x2, var.equal = FALSE)$p.value
    p_pooled <- t.test(x1, x2, var.equal = TRUE)$p.value
    tibble(p_welch = p_welch, p_pooled = p_pooled)
  })
}

scenarios <- list(
  list(n1=20, n2=20, s1=2, s2=2, label="Equal n, Equal σ"),
  list(n1=20, n2=20, s1=1, s2=3, label="Equal n, σ1=1, σ2=3"),
  list(n1=10, n2=30, s1=1, s2=3, label="Small n₁, σ1=1, σ2=3 (n∝σ²)"),
  list(n1=30, n2=10, s1=1, s2=3, label="Large n₁, σ1=1, σ2=3 (n anti-∝σ²)")
)

results <- map_dfr(scenarios, function(sc) {
  sim_ttest(sc$n1, sc$n2, sc$s1, sc$s2, B = 3000) |>
    summarise(Welch = mean(p_welch < 0.05),
              Pooled = mean(p_pooled < 0.05)) |>
    mutate(Scenario = sc$label)
})

results |>

  ggplot(aes(x = reorder(Scenario, -TypeI_Error), y = TypeI_Error, fill = Test)) +

Report Both

Example: Pooled t-Test When Appropriate

Devore Example (DBC 9.5): Two independent groups of adult male patients measured for systolic blood pressure: - Group 1 (standard care): \(n_1 = 12\), \(\bar{x}_1 = 140.2\), \(s_1 = 14.3\) mmHg - Group 2 (intensive care): \(n_2 = 10\), \(\bar{x}_2 = 128.7\), \(s_2 = 13.8\) mmHg

Strong prior reason to assume equal population SDs (same measurement, similar populations). Test \(H_0: \mu_1 = \mu_2\) vs. \(H_a: \mu_1 \neq \mu_2\) at \(\alpha = 0.05\).

n1 <- 12; xbar1 <- 140.2; s1 <- 14.3
n2 <- 10; xbar2 <- 128.7; s2 <- 13.8

# Pooled variance
sp2 <- ((n1-1)*s1^2 + (n2-1)*s2^2) / (n1 + n2 - 2)
sp  <- sqrt(sp2)

# Test statistic
t_obs <- (xbar1 - xbar2) / (sp * sqrt(1/n1 + 1/n2))
df    <- n1 + n2 - 2

# Two-sided p-value and 95% CI
p_val <- 2 * pt(abs(t_obs), df = df, lower.tail = FALSE)
t_crit <- qt(0.975, df = df)
margin <- t_crit * sp * sqrt(1/n1 + 1/n2)

cat(sprintf("Pooled SD = %.2f,  df = %d\n", sp, df))
Pooled SD = 14.08,  df = 20
cat(sprintf("T_obs = %.3f,  p-value = %.4f\n", t_obs, p_val))
T_obs = 1.908,  p-value = 0.0709
cat(sprintf("95%% CI: (%.2f, %.2f)\n", xbar1 - xbar2 - margin,
                                        xbar1 - xbar2 + margin))
95% CI: (-1.07, 24.07)

Conclusion: \(t = 1.908\), \(df = 20\), \(p = 0.0709\). At \(\alpha = 0.05\), we reject \(H_0\); evidence that systolic BP differs between care groups.

Sample Size and Power

Sample Size for Two-Sample t-Test

For a two-sided test at level \(\alpha\) with power \(1 - \beta\) to detect \(|\mu_1 - \mu_2| = \delta\) (assuming \(\sigma_1 = \sigma_2 = \sigma\) and \(n_1 = n_2 = n\)):

\[n \approx \frac{2\sigma^2(z_{\alpha/2} + z_\beta)^2}{\delta^2}\]

# Clinical question: How many patients per arm to detect a 10 mmHg difference
# in SBP with 90% power at alpha = 0.05 (two-sided)?
sigma <- 15   # assumed common SD (mmHg)
delta <- 10   # target difference to detect
alpha <- 0.05
power <- 0.90

z_a2 <- qnorm(1 - alpha/2)
z_b  <- qnorm(power)

n_per_arm <- ceiling(2 * sigma^2 * (z_a2 + z_b)^2 / delta^2)
cat("Approximate n per arm:", n_per_arm, "\n")
Approximate n per arm: 48 
# Cross-check with power.t.test
power.t.test(delta = delta, sd = sigma, sig.level = alpha, 
             power = power, type = "two.sample", alternative = "two.sided")

Key Takeaways

Key Takeaways

Today’s Main Points (DBC 9.5)

  1. Point estimator: \(\bar{X}_1 - \bar{X}_2\) is unbiased for \(\mu_1 - \mu_2\) with variance \(\sigma_1^2/n_1 + \sigma_2^2/n_2\)

  2. z-procedures: Use when \(\sigma_1^2, \sigma_2^2\) known (or large samples approximation)

  3. Welch t-test (recommended default): approximates the sampling distribution of the standardized difference with \(t_{\hat\nu}\); the Welch-Satterthwaite df \(\hat\nu\) accounts for unequal variances

  4. Pooled t-test: Exact \(t_{n_1+n_2-2}\) distribution under normality + \(\sigma_1^2 = \sigma_2^2\); requires strong prior justification for equal variances

  5. CI-test duality: The 95% CI for \(\Delta = \mu_1 - \mu_2\) contains all values of \(\Delta_0\) for which the two-sided test would fail to reject at \(\alpha = 0.05\)

  6. Always report the estimated difference, its CI, and the p-value together
