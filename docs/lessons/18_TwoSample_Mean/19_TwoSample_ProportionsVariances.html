Two independent samples for means:

  • z-procedures: \(\sigma_1^2, \sigma_2^2\) known → pivot \(Z \sim N(0,1)\)

Two-Sample Inference for Proportions (DBC 9.6)

Setup: Two Independent Bernoulli Samples

Group 1: \(X_{11}, \ldots, X_{1n_1} \stackrel{iid}{\sim} \text{Bernoulli}(p_1)\)

Group 2: \(X_{21}, \ldots, X_{2n_2} \stackrel{iid}{\sim} \text{Bernoulli}(p_2)\)

Independent groups. Observed counts: \(Y_1 = \sum X_{1j} \sim \text{Bin}(n_1, p_1)\), \(Y_2 = \sum X_{2j} \sim \text{Bin}(n_2, p_2)\).

Parameter of interest: \(\Delta = p_1 - p_2\)

Point estimator: \(\hat\Delta = \hat{p}_1 - \hat{p}_2 = Y_1/n_1 - Y_2/n_2\)

Sampling distribution (by CLT, large samples):

\[\hat{p}_1 - \hat{p}_2 \;\dot{\sim}\; N\!\left(p_1 - p_2,\; \frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}\right)\]

Standard error: \[\sigma_{\hat\Delta} = \sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}}\]

CI for \(p_1 - p_2\)

Plugging in \(\hat{p}_1\) and \(\hat{p}_2\) for the unknown \(p_1, p_2\) gives the Wald CI (DBC 9.6):

\[(\hat{p}_1 - \hat{p}_2) \pm z_{\alpha/2} \sqrt{\frac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \frac{\hat{p}_2(1-\hat{p}_2)}{n_2}}\]

Rule of Thumb for Large Sample Approximation

The normal approximation is adequate when: \[n_i \hat{p}_i \geq 5 \quad \text{and} \quad n_i(1-\hat{p}_i) \geq 5 \quad \text{for } i = 1, 2\] For rare events or small \(n\), use Fisher’s exact test or bootstrap CI (Lesson 21).

Hypothesis Testing for \(p_1 - p_2\)

Test: \(H_0: p_1 = p_2\) vs \(H_a: p_1 \neq p_2\) (or one-sided)

Under \(H_0\), both groups share a common \(p\). Estimate it by the pooled proportion: \[\hat{p} = \frac{Y_1 + Y_2}{n_1 + n_2}\]

Pooled z-statistic (use for hypothesis tests): \[Z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}\]

Pooled vs. Unpooled SE

  • Test: Use pooled \(\hat{p}\) because \(H_0\) states \(p_1 = p_2\) — we exploit this constraint.
  • CI: Use unpooled \(\hat{p}_1, \hat{p}_2\) because we make no assumption about \(p_1 = p_2\).

Medical Example: Adverse Event Rates

Clinical Trial: A drug trial compares 30-day serious adverse event (SAE) rates between treatment arm (\(n_1 = 150\), \(y_1 = 12\) SAEs) and control (\(n_2 = 148\), \(y_2 = 24\) SAEs).

Test \(H_0: p_1 = p_2\) vs. \(H_a: p_1 \neq p_2\) at \(\alpha = 0.05\) and construct a 95% CI.

n1 <- 150; y1 <- 12
n2 <- 148; y2 <- 24

p1_hat <- y1/n1; p2_hat <- y2/n2
p_pool <- (y1 + y2)/(n1 + n2)

# Test statistic (pooled SE)
se_pool <- sqrt(p_pool*(1-p_pool)*(1/n1 + 1/n2))
z_stat  <- (p1_hat - p2_hat) / se_pool
p_val   <- 2 * pnorm(abs(z_stat), lower.tail = FALSE)

# 95% CI (unpooled SE)
se_ci <- sqrt(p1_hat*(1-p1_hat)/n1 + p2_hat*(1-p2_hat)/n2)
ci    <- (p1_hat - p2_hat) + c(-1,1) * qnorm(0.975) * se_ci

Relative Risk and Odds Ratio (Brief)

The difference \(p_1 - p_2\) is one measure of treatment effect. In medical research, two ratios are commonly reported:

\[\text{Relative Risk (RR)} = \frac{p_1}{p_2}, \qquad \text{Odds Ratio (OR)} = \frac{p_1/(1-p_1)}{p_2/(1-p_2)}\]

# Estimated RR and OR
RR <- p1_hat / p2_hat
OR <- (p1_hat/(1-p1_hat)) / (p2_hat/(1-p2_hat))

# Log-scale CIs (normal approximation)
log_RR_ci <- log(RR) + c(-1,1) * qnorm(0.975) * 
             sqrt(1/y1 - 1/n1 + 1/y2 - 1/n2)  # approx SE(log RR)
log_OR_ci <- log(OR) + c(-1,1) * qnorm(0.975) *
             sqrt(1/y1 + 1/(n1-y1) + 1/y2 + 1/(n2-y2))

cat(sprintf("RR = %.3f (95%% CI: %.3f, %.3f)\n",
            RR, exp(log_RR_ci[1]), exp(log_RR_ci[2])))
RR = 0.493 (95% CI: 0.256, 0.949)
cat(sprintf("OR = %.3f (95%% CI: %.3f, %.3f)\n",
            OR, exp(log_OR_ci[1]), exp(log_OR_ci[2])))
OR = 0.449 (95% CI: 0.216, 0.936)

Interpretation: The treatment arm had approximately half the SAE rate of control (RR ≈ 0.49), though the CI crosses values that would be borderline.

Inferences About Two Variances (DBC 9.6)

The F-Distribution

When comparing variability between two groups, we use the F-distribution.

Setup: If \(S_1^2\) and \(S_2^2\) are sample variances from independent normal samples:

\[F = \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} = \frac{S_1^2}{S_2^2} \cdot \frac{\sigma_2^2}{\sigma_1^2} \sim F_{n_1-1,\,n_2-1}\]

where \(F_{m,n}\) denotes the F-distribution with \(m\) numerator and \(n\) denominator degrees of freedom.

Key Properties of \(F_{m,n}\): - Support: \((0, \infty)\); right-skewed - \(E[F] = n/(n-2)\) for \(n > 2\) - If \(F \sim F_{m,n}\), then \(1/F \sim F_{n,m}\) (reciprocal relationship) - \(F_{m,\infty} \sim \chi^2_m / m\) - Critical values: qf(p, df1, df2) in R

F-Test for \(H_0: \sigma_1^2 = \sigma_2^2\)

Under \(H_0: \sigma_1^2 = \sigma_2^2\): The pivot simplifies to \(F = S_1^2/S_2^2 \sim F_{n_1-1,\,n_2-1}\)

Test statistic: \(f = s_1^2/s_2^2\)

Alternative Rejection Region p-value
\(\sigma_1^2 > \sigma_2^2\) \(F > F_{\alpha,\,n_1-1,\,n_2-1}\) \(P(F \geq f)\)
\(\sigma_1^2 < \sigma_2^2\) \(F < F_{1-\alpha,\,n_1-1,\,n_2-1}\) \(P(F \leq f)\)
\(\sigma_1^2 \neq \sigma_2^2\) \(F < F_{1-\alpha/2}\) or \(F > F_{\alpha/2}\) \(2\min(P(F \leq f), P(F \geq f))\)

CI for \(\sigma_1^2/\sigma_2^2\):

\[\left(\frac{s_1^2/s_2^2}{F_{\alpha/2,\,n_1-1,\,n_2-1}},\;\; \frac{s_1^2/s_2^2}{F_{1-\alpha/2,\,n_1-1,\,n_2-1}}\right)\]

Note: \(F_{1-\alpha/2,\,m,n} = 1/F_{\alpha/2,\,n,m}\) (use the reciprocal relationship in tables).

Medical Example: Comparing Lab Variability

Example (DBC 9.6 style): Two clinical laboratories each measure serum potassium (mEq/L) on the same set of patient samples. Concern: Does one lab have higher measurement variability?

  • Lab 1: \(n_1 = 16\) samples, \(s_1 = 0.38\) mEq/L
  • Lab 2: \(n_2 = 21\) samples, \(s_2 = 0.22\) mEq/L

Test \(H_0: \sigma_1^2 = \sigma_2^2\) vs. \(H_a: \sigma_1^2 > \sigma_2^2\) at \(\alpha = 0.05\).

n1 <- 16; s1 <- 0.38
n2 <- 21; s2 <- 0.22
alpha <- 0.05

# F statistic and p-value (one-sided: sigma1 > sigma2)
f_stat <- s1^2 / s2^2
df1    <- n1 - 1
df2    <- n2 - 1
p_val  <- pf(f_stat, df1 = df1, df2 = df2, lower.tail = FALSE)

# 95% CI for sigma1^2/sigma2^2
f_lo <- qf(alpha/2,   df1 = df1, df2 = df2)
f_hi <- qf(1-alpha/2, df1 = df1, df2 = df2)
ci   <- c(f_stat/f_hi, f_stat/f_lo)

cat("F statistic:", round(f_stat, 3), "\n")
F statistic: 2.983 
cat("df: (", df1, ",", df2, ")\n")
df: ( 15 , 20 )
cat("One-sided p-value:", round(p_val, 4), "\n")
One-sided p-value: 0.012 
cat("95% CI for sigma1^2/sigma2^2: (",
    round(ci[1], 3), ",", round(ci[2], 3), ")\n")
95% CI for sigma1^2/sigma2^2: ( 1.159 , 8.222 )

Conclusion: \(F = 2.983\), \(p = 0.012\). Strong evidence that Lab 1 has greater measurement variability than Lab 2.

Sensitivity to Normality

The F-test for equality of variances is extremely sensitive to non-normality — much more so than the t-test for means. For non-normal data, prefer:

  • Levene’s test (car::leveneTest()) — uses absolute deviations from medians
  • Bartlett’s test — equivalent to F-test, also sensitive to non-normality

In medical research, the F-test for variances is most useful as a descriptive tool or when normality is well-established (e.g., lab measurements).

Sensitivity of F-test to Non-normality

Code 
set.seed(551)
B <- 3000

sim_ftest <- function(dist_fn, n1 = 20, n2 = 20) {
  map_dbl(1:B, function(i) {
    x1 <- dist_fn(n1)
    x2 <- dist_fn(n2)
    var.test(x1, x2)$p.value
  })
}

# Under H0 (same distribution): should reject ~5% of the time
p_norm   <- sim_ftest(function(n) rnorm(n))
p_t3     <- sim_ftest(function(n) rt(n, df = 3))
p_exp    <- sim_ftest(function(n) rexp(n))
p_chisq5 <- sim_ftest(function(n) rchisq(n, df = 5))

tibble(
  p_value = c(p_norm, p_t3, p_exp, p_chisq5),
  Distribution = rep(c("Normal", "t(3) — heavy tails",
                        "Exponential — skewed", "χ²(5) — skewed"),
                     each = B)
) |>
  group_by(Distribution) |>
  summarise(RejectionRate = mean(p_value < 0.05)) |>
  ggplot(aes(x = reorder(Distribution, RejectionRate),
             y = RejectionRate, fill = Distribution)) +
  geom_col(width = 0.55) +
  geom_hline(yintercept = 0.05, linetype = "dashed", linewidth = 1.1) +
  scale_fill_brewer(palette = "Set2") +
  scale_y_continuous(labels = scales::percent, limits = c(0, 0.3),
                     expand = expansion(mult = c(0, 0.05))) +
  labs(title = "F-Test Type I Error Under H₀ (σ₁=σ₂) for Non-Normal Distributions",
       subtitle = "F-test is severely inflated for heavy-tailed and skewed data. Nominal level = 5%.",
       x = NULL, y = "Rejection Rate (α = 0.05)", fill = NULL) +

Key Takeaways

Key Takeaways

Today’s Main Points (DBC 9.6)

  1. Two-sample proportions: \(\hat{p}_1 - \hat{p}_2\) is approximately normal (CLT). Use pooled SE for the test (under \(H_0: p_1 = p_2\)) and unpooled SE for the CI

  2. Large-sample condition: Need \(n_i \hat{p}_i \geq 5\) and \(n_i(1-\hat{p}_i) \geq 5\); otherwise use Fisher’s exact test or bootstrap

  3. F-distribution: Ratio of two independent scaled chi-squared variables; \(S_1^2/S_2^2 \sim F_{n_1-1,\,n_2-1}\) under \(H_0: \sigma_1^2 = \sigma_2^2\) and normality

  4. F-test for equal variances: Exact under normality but very sensitive to non-normality — use Levene’s test in practice for non-normal data

  5. CI for \(\sigma_1^2/\sigma_2^2\): Asymmetric interval based on F critical values; check whether 1 is inside (evidence for equal variances)

  6. Clinical reporting: Always report point estimates + CIs; choose measure of effect (RD, RR, OR) that is most interpretable in context
