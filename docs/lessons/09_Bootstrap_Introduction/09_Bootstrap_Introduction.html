The Key Question

How can we construct confidence intervals when:

  1. The population distribution is unknown or non-normal?
  2. The sample size is too small for CLT to apply reliably?
  3. We want to estimate parameters other than the mean (median, trimmed mean, ratio)?

The Bootstrap Solution

Use the data itself to approximate the sampling distribution of our statistic!

The Bootstrap Idea

What is the Bootstrap?

Definition (Devore, Berk, Carlton 8.5)

The bootstrap is a resampling method that uses the observed sample to approximate the sampling distribution of a statistic.

The method was developed by Bradley Efron in the late 1970s and substitutes heavy computation for theoretical derivation.

Key insight: The sample is our best estimate of the population. If we resample from the sample, we can learn about sampling variability.

Traditional vs. Bootstrap Approach

Traditional Inference:

  1. Assume population distribution (e.g., Normal)
  2. Derive sampling distribution theoretically
  3. Use theoretical distribution to construct intervals

Bootstrap Inference:

  1. Use the sample as a proxy for the population
  2. Generate sampling distribution empirically via resampling
  3. Use empirical distribution for inference

The Plug-In Principle (Chihara & Hesterberg 5.2)

The Plug-In Principle

To estimate a parameter (a quantity that describes the population), use the statistic that is the corresponding quantity for the sample.

Examples:

Population Parameter Sample Statistic
Mean \(\mu\) \(\bar{x}\)
Standard deviation \(\sigma\) \(s\)
Median \(\tilde{\mu}\) Sample median
Standard error \(\sigma/\sqrt{n}\) \(s/\sqrt{n}\)

The bootstrap extends this: Use the entire sample as an estimate of the entire population.

The Empirical Distribution Function

Definition: Empirical CDF

Given a sample \(x_1, x_2, \ldots, x_n\), the empirical cumulative distribution function is: \[\hat{F}_n(x) = \frac{1}{n}\#\{x_i \leq x\} = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}(x_i \leq x)\]

This assigns probability \(1/n\) to each observed data point.

Key properties of \(\hat{F}_n\):

  • \(E_{\hat{F}}[X] = \bar{x}\) (mean under empirical distribution = sample mean)
  • \(\text{Var}_{\hat{F}}[X] = \frac{1}{n}\sum(x_i - \bar{x})^2\) (slightly different from \(s^2\))

Sampling Distribution vs. Bootstrap Distribution

Sampling Distribution:

  • Draw many samples from the population
  • Calculate statistic for each
  • Distribution of these statistics

In practice: We can’t do this (we only have one sample!)

Bootstrap Distribution:

  • Draw many resamples from the sample
  • Calculate statistic for each
  • Distribution of these statistics

In practice: We can do this computationally!

Key Point

The bootstrap distribution approximates the sampling distribution, allowing us to estimate standard errors and construct confidence intervals.

Why Sampling WITH Replacement?

The Critical Question

Why must we sample with replacement rather than without replacement (subsampling)?

Without Replacement

If we sample without replacement from our sample of size \(n\), we would get:

  • A subsample of size \(m < n\): Less information, different properties
  • A sample of size \(n\): Exactly the same sample every time!

Sampling with replacement allows:

  1. Observations to appear multiple times (or not at all)
  2. Variability in the bootstrap samples
  3. Approximation of the sampling process from the population

Mathematical Justification

Why Replacement Matters

When sampling from a population of size \(N\), we sample with replacement because:

  1. The population is treated as infinite (or very large relative to \(n\))
  2. Each draw is independent of previous draws
  3. Each observation has the same probability of selection

The empirical distribution \(\hat{F}_n\) is a discrete distribution with \(n\) equally likely values. Sampling from it with replacement mimics sampling from the true population.

Number of Possible Bootstrap Samples

Counting Bootstrap Samples

For a sample of size \(n\), the number of possible bootstrap samples (sampling \(n\) with replacement) is: \[\binom{2n-1}{n-1} = \binom{2n-1}{n}\]

This is the number of ways to choose \(n\) items from \(n\) categories with repetition allowed.

The Variance Connection

Variance of Bootstrap Mean

For the sample mean, the theoretical (exhaustive) bootstrap standard error is: \[SE_{boot}(\bar{X}^*) = \frac{\hat{\sigma}}{\sqrt{n}} = \sqrt{\frac{1}{n^2}\sum_{i=1}^{n}(x_i - \bar{x})^2}\]

where \(\hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \bar{x})^2\) is the population variance under \(\hat{F}_n\).

Note: This differs slightly from \(s/\sqrt{n}\) by a factor of \(\sqrt{(n-1)/n}\): \[SE_{boot} = \sqrt{\frac{n-1}{n}} \cdot \frac{s}{\sqrt{n}}\]

This is why bootstrap SEs are slightly narrower than classical SEs.

Subsampling: An Alternative Approach

Subsampling (Without Replacement)

An alternative to bootstrap is subsampling: draw samples of size \(m < n\) without replacement.

Properties:

  • Requires choosing subsample size \(m\)
  • Typically \(m/n \to 0\) as \(n \to \infty\)
  • Can work when bootstrap fails (heavy tails, dependent data)
  • Generally less efficient than bootstrap

When to use subsampling:

  • Time series or dependent data
  • Estimating extreme quantiles
  • When bootstrap consistency fails

The Bootstrap Method

Basic Bootstrap Algorithm (Devore 8.5)

Basic Bootstrap Method

Given a sample \(x_1, x_2, \ldots, x_n\) and a statistic \(\hat{\theta}\):

  1. Resample: Draw a sample of size \(n\) with replacement from \(x_1, \ldots, x_n\)
  2. Compute: Calculate \(\hat{\theta}^*\) from this bootstrap sample
  3. Repeat: Repeat steps 1-2 many times (typically \(B = 1000\) to \(10000\))
  4. Analyze: Use the distribution of \(\hat{\theta}^*_1, \hat{\theta}^*_2, \ldots, \hat{\theta}^*_B\) for inference

Why sample with replacement?

Without replacement, we’d get the same sample every time!

Bootstrap in R: Step by Step

# Original response time data
response_times <- c(8, 12, 15, 7, 22, 45, 11, 9, 14, 18, 10, 13)
n <- length(response_times)
B <- 10000  # Number of bootstrap samples

# Storage for bootstrap means
boot_means <- numeric(B)

# Bootstrap loop
for (i in 1:B) {
  # Step 1: Resample with replacement
  boot_sample <- sample(response_times, size = n, replace = TRUE)
  
  # Step 2: Calculate statistic
  boot_means[i] <- mean(boot_sample)
}

Asymptotic Properties of Bootstrap

Bootstrap Consistency

Bootstrap Consistency Theorem

Under regularity conditions, the bootstrap distribution consistently estimates the sampling distribution. Specifically:

Let \(\hat{\theta}_n\) be an estimator of \(\theta\) based on a sample of size \(n\). If: \[\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N(0, \sigma^2)\]

Then under the bootstrap: \[\sqrt{n}(\hat{\theta}_n^* - \hat{\theta}_n) \xrightarrow{d} N(0, \sigma^2)\]

where convergence is in probability.

In plain English: The bootstrap distribution mimics the true sampling distribution as \(n \to \infty\).

What Bootstrap Estimates Well

Bootstrap Accurately Estimates (Chihara 5.2.2)

  1. Spread: The spread (standard error) of the sampling distribution
  2. Shape: The shape (including skewness) of the sampling distribution
  3. Bias: The bias of the estimator

Bootstrap Does NOT Estimate

Center: The bootstrap distribution is centered at \(\hat{\theta}\) (the sample statistic), NOT at \(\theta\) (the true parameter).

This means bootstrap cannot improve point estimates!

When Bootstrap Fails

Bootstrap Failure Modes

The bootstrap is not a universal solution. It can fail when:

  1. Very small samples (\(n < 10\))
  2. Sample doesn’t represent population
  3. Estimating extreme quantiles
  4. Discrete statistics (e.g., median with few unique values)
  5. Heavy-tailed distributions (infinite variance)
  6. Dependent data (time series, spatial data)
  7. Lattice distributions with small support

Why Median Bootstrap Fails

The Median Problem (Chihara 5.8.3)

For odd sample size \(n\), the bootstrap median can only take values that are observations in the original sample.

Consequences:

  • Bootstrap distribution is discrete, not continuous
  • Shape depends heavily on gaps between observations
  • May poorly approximate the continuous sampling distribution

Remedies:

  • Smoothed bootstrap: Add small noise to observations
  • Larger samples: Problem diminishes as \(n\) increases
  • Use percentile intervals rather than bootstrap t

Failure Mode 3: Heavy-Tailed Distributions

Cauchy Distribution Example

The Cauchy distribution has no mean (undefined). For such distributions:

  • Sample mean is not consistent
  • Bootstrap cannot “fix” an inconsistent estimator
  • Bootstrap distribution doesn’t converge properly

Failure Mode 4: Extreme Quantiles

Estimating Extreme Quantiles

Bootstrap has difficulty with extreme quantiles (e.g., 99th percentile) because:

  1. Few observations near the tail
  2. Bootstrap samples may not include extreme values
  3. Standard bootstrap underestimates tail variability

set.seed(551)

Summary and Looking Ahead

Key Takeaways: The Bootstrap Principle

The Bootstrap Principle

  1. The sample represents the population — resample from the sample
  2. Sampling with replacement mimics drawing new samples
  3. Bootstrap distribution approximates sampling distribution
  4. Use bootstrap to estimate standard errors and the shape of the sampling distribution

Main advantages:

  • No distributional assumptions required
  • Works for any statistic (medians, ratios, etc.)
  • Computationally straightforward

Why Resampling WITH Replacement?

Key Points

  1. Without replacement: Would get the same sample every time (size \(n\))
  2. With replacement: Creates variability that mimics sampling from population
  3. Empirical distribution: Assigns probability \(1/n\) to each observation
  4. Number of bootstrap samples: \(\binom{2n-1}{n}\) possible — astronomically large!

Asymptotic Properties Summary

Bootstrap Consistency

Under regularity conditions:

  • Bootstrap distribution converges to sampling distribution
  • Bootstrap SE consistently estimates true SE
  • Bootstrap t intervals have coverage error \(O(n^{-1})\) — better than percentile!

The bootstrap accurately estimates:

  • Spread (standard error)
  • Shape (including skewness)
  • Bias

But NOT the center (stays at \(\hat{\theta}\), not \(\theta\))

When Bootstrap Fails: Summary
