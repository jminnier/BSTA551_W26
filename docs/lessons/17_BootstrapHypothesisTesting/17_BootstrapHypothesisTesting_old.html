Why This Matters

Parametric tests (z, t, F) require distributional assumptions that may not hold in practice. Bootstrap and permutation tests provide distribution-free alternatives that are valid under much weaker conditions — essential for small samples, skewed outcomes, and novel statistics in biomedical research.

The Bootstrap Hypothesis Test Framework (C&H Ch. 8)

Bootstrap CI vs. Bootstrap Test: Different Goals

We have used the bootstrap to construct confidence intervals (Lessons 9–10). Now we use it for hypothesis testing. The ideas are related but not identical.

Bootstrap CI Bootstrap Hypothesis Test
Resample from estimated distribution Resample from distribution under \(H_0\)
Goal: capture sampling variability of \(\hat{\theta}\) Goal: approximate null distribution of test statistic
CI covers \(\theta\) with \(\approx 1-\alpha\) probability Null distribution used to compute p-value

Core Principle (C&H 8.1)

A bootstrap hypothesis test approximates the null distribution of the test statistic by resampling from a population that satisfies \(H_0\). The p-value is the fraction of bootstrap statistics at least as extreme as the observed value.

The Bootstrap Test: General Algorithm

Setup: Observe \(x_1, \ldots, x_n\). Test \(H_0: \theta = \theta_0\) vs. \(H_a: \theta \neq \theta_0\). Let \(T = T(x_1,\ldots,x_n)\) be a test statistic.

Algorithm:

  1. Compute the observed test statistic \(T_{\text{obs}} = T(x_1, \ldots, x_n)\)

  2. Shift the data to satisfy \(H_0\): define \(x_i^* = x_i - \bar{x} + \theta_0\) (so the shifted sample has mean exactly \(\theta_0\))

  3. For \(b = 1, \ldots, B\):

    • Draw a bootstrap sample \(x_1^{*b}, \ldots, x_n^{*b}\) with replacement from \((x_1^*, \ldots, x_n^*)\)
    • Compute \(T^{*b} = T(x_1^{*b}, \ldots, x_n^{*b})\)

  4. Compute p-value: \[\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}(|T^{*b}| \geq |T_{\text{obs}}|)\]

Why Shift the Data?

The fundamental challenge: we observe data from the true distribution (with \(\theta \neq \theta_0\) possibly), but we need to approximate the distribution of \(T\) under \(H_0\).

Shifting: By replacing \(x_i\) with \(x_i^* = x_i - \bar{x} + \theta_0\), we create a dataset that:

  • Has the same shape and variability as the original
  • Has mean exactly equal to \(\theta_0\) (satisfying \(H_0: \mu = \theta_0\))

One-Sample Bootstrap Test (C&H 8.1)

Full Implementation: One-Sample Bootstrap Test

Medical Context: A hospital monitors C-reactive protein (CRP, mg/L) as an inflammation marker. The healthy adult population norm is mean CRP = 1.5 mg/L. We observe a small sample of post-surgical patients and test whether their mean CRP differs from this norm.

\[H_0: \mu = 1.5 \quad \text{vs} \quad H_a: \mu \neq 1.5\]

Code 
set.seed(551)
n_crp <- 22
# Gamma(shape=2, rate=1): mean = 2, SD ≈ 1.41 — right-skewed, moderate elevation
crp_data <- rgamma(n_crp, shape = 2, rate = 1)

mu_0 <- 1.5
B    <- 5000

# Observed test statistic (t-statistic)
T_obs <- (mean(crp_data) - mu_0) / (sd(crp_data) / sqrt(n_crp))

# Shift data to satisfy H0
crp_shifted <- crp_data - mean(crp_data) + mu_0

# Bootstrap
T_boot <- replicate(B, {
  boot_samp <- sample(crp_shifted, size = n_crp, replace = TRUE)
  (mean(boot_samp) - mu_0) / (sd(boot_samp) / sqrt(n_crp))
})

# Bootstrap p-value (two-sided)
p_boot <- mean(abs(T_boot) >= abs(T_obs))

# Parametric t-test p-value
p_param <- t.test(crp_data, mu = mu_0)$p.value

When Does the Bootstrap Test Outperform the t-Test?

Code 
# Compare rejection rates under H0 (alpha control) for normal vs skewed distributions
sim_compare <- function(n, dist = "normal", B_inner = 999, reps = 500) {
  replicate(reps, {
    if (dist == "normal") {
      x <- rnorm(n, mean = 0)
    } else {
      x <- rexp(n, rate = 1) - 1  # centered exponential (mean=0, skewed)
    }
    
    # t-test p-value
    p_t <- t.test(x, mu = 0)$p.value
    
    # Bootstrap p-value
    x_sh <- x - mean(x)  # shift to H0: mu = 0
    T_ob <- (mean(x)) / (sd(x) / sqrt(n))
    T_bs <- replicate(B_inner, {
      bs <- sample(x_sh, n, replace = TRUE)
      (mean(bs)) / (sd(bs) / sqrt(n))
    })
    p_bs <- mean(abs(T_bs) >= abs(T_ob))
    
    c(p_t = p_t, p_bs = p_bs)
  }) |>
    t() |>
    as_tibble() |>
    summarise(
      alpha_t  = mean(p_t < 0.05),
      alpha_bs = mean(p_bs < 0.05),
      .groups = "drop"
    ) |>
    mutate(n = n, dist = dist)
}

set.seed(42)
grid <- expand_grid(n = c(10, 25, 50), dist = c("normal", "skewed"))
res <- map2_dfr(grid$n, grid$dist, sim_compare)

res |>
  pivot_longer(starts_with("alpha"), names_to = "method", values_to = "type1") |>
  mutate(
    method = recode(method, alpha_t = "t-test", alpha_bs = "Bootstrap test"),
    dist   = recode(dist, normal = "Normal population", skewed = "Skewed population (Exp-1)")
  ) |>
  ggplot(aes(x = factor(n), y = type1, fill = method)) +
  geom_col(position = "dodge", alpha = 0.85) +
  geom_hline(yintercept = 0.05, linetype = "dashed", color = "black", linewidth = 1) +
  facet_wrap(~dist) +
  scale_fill_manual(values = c("t-test" = "steelblue", "Bootstrap test" = "#27ae60")) +
  scale_y_continuous(labels = scales::percent, limits = c(0, 0.12)) +
  labs(
    title = expression("Type I Error Rate Under " * H[0] * " at " * alpha * " = 0.05"),
    subtitle = "Both methods well-calibrated for normal; bootstrap slightly better for small skewed samples",
    x = "Sample size (n)", y = "Empirical Type I error rate",

  ) +

Two-Sample Bootstrap Test (C&H 8.2)

Two-Sample Setting

Goal: Test \(H_0: \mu_1 = \mu_2\) (or equivalently \(H_0: \mu_1 - \mu_2 = 0\)) from two independent samples.

Parametric approach: Two-sample t-test (requires approximate normality, or large \(n\)).

Bootstrap approach: Must resample in a way that respects \(H_0: \mu_1 = \mu_2\).

Key Idea: Pool Under \(H_0\) (C&H 8.2)

Under \(H_0: \mu_1 = \mu_2\), both groups come from distributions with the same mean. We can center each group by subtracting its own sample mean, then pool the centered data. Resampling from this pooled centered data generates bootstrap samples that satisfy \(H_0\).

Two-Sample Bootstrap Algorithm

Given: \(x_{1,1}, \ldots, x_{1,n_1}\) from Group 1 and \(x_{2,1}, \ldots, x_{2,n_2}\) from Group 2.

Observed statistic: \(T_{\text{obs}} = \bar{x}_1 - \bar{x}_2\) (or t-statistic).

Algorithm (C&H 8.2):

  1. Center each group: \(\tilde{x}_{1i} = x_{1i} - \bar{x}_1 + \bar{x}\); \(\tilde{x}_{2i} = x_{2i} - \bar{x}_2 + \bar{x}\), where \(\bar{x}\) is the grand mean of the pooled data

  2. Pool centered data: \(\tilde{\mathbf{x}} = (\tilde{x}_{1,1}, \ldots, \tilde{x}_{1,n_1}, \tilde{x}_{2,1},\ldots,\tilde{x}_{2,n_2})\)

  3. For \(b = 1, \ldots, B\):

    • Draw \(n_1\) with replacement from \(\tilde{\mathbf{x}}\) \(\to\) bootstrap Group 1
    • Draw \(n_2\) with replacement from \(\tilde{\mathbf{x}}\) \(\to\) bootstrap Group 2
    • Compute \(T^{*b} = \bar{x}_1^{*b} - \bar{x}_2^{*b}\)

  4. p-value: \(\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}(|T^{*b}| \geq |T_{\text{obs}}|)\)

Permutation Tests (C&H 8.3)

The Permutation Test Idea

Key Principle (C&H 8.3)

Under \(H_0: \mu_1 = \mu_2\) (or more generally, \(H_0\): the two groups are exchangeable), the group labels are arbitrary — any assignment of observations to groups is equally likely.

A permutation test generates the exact null distribution of the test statistic by considering all possible (or a large random sample of) permutations of the group labels.

Algorithm:

  1. Compute observed statistic \(T_{\text{obs}} = \bar{x}_1 - \bar{x}_2\)
  2. For \(b = 1, \ldots, B\):
    • Randomly permute the combined vector of \(n_1 + n_2\) observations
    • Assign first \(n_1\) to Group 1, remaining \(n_2\) to Group 2
    • Compute \(T^{*b} = \bar{x}_1^{*b} - \bar{x}_2^{*b}\)
  3. p-value: \(\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}(|T^{*b}| \geq |T_{\text{obs}}|)\)

Exact vs. Approximate

With total \(n_1+n_2\) observations, there are \(\binom{n_1+n_2}{n_1}\) permutations. If this is small, we can enumerate all of them for an exact test. Otherwise, random permutations give a Monte Carlo approximation of the exact test.

Permutation Test vs. Bootstrap Test: The Key Distinction

Feature Bootstrap Test Permutation Test
How \(H_0\) is imposed Shift/center data to satisfy \(H_0\) Permute group labels
What is resampled From modified data From original data
Validity assumption \(H_0\) + iid resampling Exchangeability under \(H_0\)
When exact? Never (always approximate) Yes, if all permutations enumerated
Handles one-sample? Yes (shift to \(\theta_0\)) Not naturally
Computes standard errors? Yes No

When to Prefer Permutation Tests

Permutation tests are preferred when: - You want an exact p-value under \(H_0\) - Exchangeability is a natural assumption (randomized trials!) - You want a valid test without distributional assumptions

# Under H0: compare Type I error
# Under Ha: compare power

run_three_tests <- function(n1 = 20, n2 = 20, delta = 0,
                            dist = "normal", B_inner = 499) {
  if (dist == "normal") {
    x1 <- rnorm(n1, mean = delta); x2 <- rnorm(n2, mean = 0)
  } else {
    x1 <- rexp(n1, 1) - 1 + delta; x2 <- rexp(n2, 1) - 1
  }

  # Parametric t-test
  p_t <- t.test(x1, x2)$p.value

  # Bootstrap (pooled centered)
  grand <- mean(c(x1, x2))
  x1c   <- x1 - mean(x1) + grand
  x2c   <- x2 - mean(x2) + grand
  pool  <- c(x1c, x2c)
  T_ob  <- mean(x1) - mean(x2)
  T_bs  <- replicate(B_inner, {
    mean(sample(pool, n1, T)) - mean(sample(pool, n2, T))
  })
  p_b <- mean(abs(T_bs) >= abs(T_ob))

  # Permutation
  comb  <- c(x1, x2)
  T_pm  <- replicate(B_inner, {
    pm <- sample(comb)
    mean(pm[1:n1]) - mean(pm[(n1+1):(n1+n2)])
  })
  p_p <- (sum(abs(T_pm) >= abs(T_ob)) + 1) / (B_inner + 1)

  c(p_t = p_t, p_boot = p_b, p_perm = p_p)
}

Practical Advice for Biostatistics

In clinical trials with randomized treatment assignment, permutation tests are the gold standard — they require only the randomization mechanism, not any population model. For observational studies, bootstrap tests offer robustness to non-normality without assuming exchangeability.

Bootstrap Tests and the Duality with CIs

Bootstrap Tests and Bootstrap CIs: Are They Dual?

In the parametric setting, we showed that confidence intervals and tests are exactly dual. Does this hold for bootstrap tests and bootstrap CIs?

Answer: Approximately, but the method matters

  • Bootstrap percentile CI ↔︎ bootstrap test based on \(\hat{\theta}\): approximately dual
  • The duality is exact only if the bootstrap CI and test use the same pivot/statistic
  • In practice, they may give slightly different inferences for small \(n\)

One-Sample Permutation Test (C&H 8.3)

One-Sample Permutation Test: Sign Test Perspective

For a one-sample test \(H_0: \mu = \mu_0\), permutation tests work via sign flipping (not label permutation).

Under \(H_0: \text{median} = \mu_0\) (or symmetry about \(\mu_0\)):

The deviations \(d_i = x_i - \mu_0\) are symmetric about 0, so each sign is equally likely to be + or −.

Algorithm:

  1. Compute \(d_i = x_i - \mu_0\) and observed \(T_{\text{obs}} = \bar{d}\)
  2. For \(b = 1, \ldots, B\): randomly assign \(\pm 1\) to each \(d_i\); compute \(T^{*b} = \bar{d}^{*b}\)
  3. p-value: fraction with \(|T^{*b}| \geq |T_{\text{obs}}|\)
# Sign-flip permutation test for mean CRP
crp_data_perm <- c(2.1, 3.4, 1.8, 4.2, 2.9, 3.7, 1.5, 5.1, 2.6, 3.8, 4.0, 2.2)
mu_0_crp <- 2.5
d <- crp_data_perm - mu_0_crp
T_obs_crp <- mean(d)

set.seed(551)

  signs <- sample(c(-1, 1), length(d), replace = TRUE)
  mean(signs * d)
})

Key Takeaways

Key Takeaways

Today’s Main Points (C&H Chapter 8)

  1. Bootstrap hypothesis tests approximate the null distribution by resampling from data shifted to satisfy \(H_0\) — this is different from bootstrap CIs

  2. One-sample bootstrap test: shift data so \(\bar{x}^* = \theta_0\), resample, compute p-value from fraction of bootstrap statistics as extreme as observed

  3. Two-sample bootstrap test: center each group to the grand mean (pool under \(H_0\)), resample from pooled centered data

  4. Permutation tests are valid under exchangeability — especially natural for randomized experiments. The group labels are permuted; exact p-values are available by enumeration

  5. Permutation \(\neq\) Bootstrap: permutation assumes exchangeability; bootstrap assumes iid resampling. Both avoid parametric distributional assumptions

  6. All three methods (parametric, bootstrap, permutation) give similar results for large normal samples; differences emerge for small \(n\), skewed data, or non-standard statistics

  7. Duality: bootstrap tests and bootstrap CIs are approximately (but not exactly) dual
