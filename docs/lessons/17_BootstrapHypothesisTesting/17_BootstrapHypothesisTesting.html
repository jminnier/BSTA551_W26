Why This Matters

Parametric tests (z, t) require distributional assumptions that may not hold in practice. The bootstrap test provides a distribution-free alternative that is valid under much weaker conditions — essential for small samples, skewed outcomes, and novel test statistics in biomedical research.

The Bootstrap Hypothesis Test Framework (C&H Ch. 8)

Bootstrap CI vs. Bootstrap Test: Different Goals

We have used the bootstrap to construct confidence intervals (Lessons 9–10). Now we use it for hypothesis testing. The ideas are related but not identical.

Bootstrap CI Bootstrap Hypothesis Test
Resample from estimated distribution Resample from distribution under \(H_0\)
Goal: capture sampling variability of \(\hat{\theta}\) Goal: approximate null distribution of test statistic
CI covers \(\theta\) with \(\approx 1-\alpha\) probability Null distribution used to compute p-value

Core Principle (C&H 8.1)

A bootstrap hypothesis test approximates the null distribution of the test statistic by resampling from a population that satisfies \(H_0\). The p-value is the fraction of bootstrap statistics at least as extreme as the observed value.

The Bootstrap Test: General Algorithm

Setup: Observe \(x_1, \ldots, x_n\). Test \(H_0: \theta = \theta_0\) vs. \(H_a: \theta \neq \theta_0\). Let \(T = T(x_1,\ldots,x_n)\) be a test statistic.

Algorithm:

  1. Compute the observed test statistic \(T_{\text{obs}} = T(x_1, \ldots, x_n)\)

  2. Shift the data to satisfy \(H_0\): define \(x_i^* = x_i - \bar{x} + \theta_0\) (so the shifted sample has mean exactly \(\theta_0\))

  3. For \(b = 1, \ldots, B\):

    • Draw a bootstrap sample \(x_1^{*b}, \ldots, x_n^{*b}\) with replacement from \((x_1^*, \ldots, x_n^*)\)
    • Compute \(T^{*b} = T(x_1^{*b}, \ldots, x_n^{*b})\)

  4. Compute p-value: \[\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}(|T^{*b}| \geq |T_{\text{obs}}|)\]

Why Shift the Data?

The fundamental challenge: we observe data from the true distribution (with \(\theta \neq \theta_0\) possibly), but we need to approximate the distribution of \(T\) under \(H_0\).

Shifting: By replacing \(x_i\) with \(x_i^* = x_i - \bar{x} + \theta_0\), we create a dataset that:

  • Has the same shape and variability as the original
  • Has mean exactly equal to \(\theta_0\) (satisfying \(H_0: \mu = \theta_0\))

One-Sample Bootstrap Test (C&H 8.1)

Full Implementation: One-Sample Bootstrap Test

Medical Context: A hospital monitors C-reactive protein (CRP, mg/L) as an inflammation marker. The healthy adult population norm is mean CRP = 1.5 mg/L. We observe a small sample of post-surgical patients and test whether their mean CRP differs from this norm.

\[H_0: \mu = 1.5 \quad \text{vs} \quad H_a: \mu \neq 1.5\]

Code 
set.seed(551)
n_crp <- 22
# Gamma(shape=2, rate=1): mean = 2, SD ≈ 1.41 — right-skewed, moderate elevation
crp_data <- rgamma(n_crp, shape = 2, rate = 1)

mu_0 <- 1.5
B    <- 5000

# Observed test statistic (t-statistic)
T_obs <- (mean(crp_data) - mu_0) / (sd(crp_data) / sqrt(n_crp))

# Shift data to satisfy H0
crp_shifted <- crp_data - mean(crp_data) + mu_0

# Bootstrap
T_boot <- replicate(B, {
  boot_samp <- sample(crp_shifted, size = n_crp, replace = TRUE)
  (mean(boot_samp) - mu_0) / (sd(boot_samp) / sqrt(n_crp))
})

# Bootstrap p-value (two-sided)
p_boot <- mean(abs(T_boot) >= abs(T_obs))

# Parametric t-test p-value
p_param <- t.test(crp_data, mu = mu_0)$p.value

When Does the Bootstrap Test Outperform the t-Test?

Code 
# Compare rejection rates under H0 (alpha control) for normal vs skewed distributions
sim_compare <- function(n, dist = "normal", B_inner = 999, reps = 500) {
  replicate(reps, {
    if (dist == "normal") {
      x <- rnorm(n, mean = 0)
    } else {
      x <- rexp(n, rate = 1) - 1  # centered exponential (mean=0, skewed)
    }
    
    # t-test p-value
    p_t <- t.test(x, mu = 0)$p.value
    
    # Bootstrap p-value
    x_sh <- x - mean(x)  # shift to H0: mu = 0
    T_ob <- (mean(x)) / (sd(x) / sqrt(n))
    T_bs <- replicate(B_inner, {
      bs <- sample(x_sh, n, replace = TRUE)
      (mean(bs)) / (sd(bs) / sqrt(n))
    })
    p_bs <- mean(abs(T_bs) >= abs(T_ob))
    
    c(p_t = p_t, p_bs = p_bs)
  }) |>
    t() |>
    as_tibble() |>
    summarise(
      alpha_t  = mean(p_t < 0.05),
      alpha_bs = mean(p_bs < 0.05),
      .groups = "drop"
    ) |>
    mutate(n = n, dist = dist)
}

set.seed(42)
grid <- expand_grid(n = c(10, 25, 50), dist = c("normal", "skewed"))
res <- map2_dfr(grid$n, grid$dist, sim_compare)

What Happens If You Don’t Shift? (A Common Mistake)

It is tempting to simply bootstrap from the original data and compare to \(\theta_0\). Why is this wrong?

The Naive Bootstrap Test — Incorrect

Resample from the original \(x_1, \ldots, x_n\) and compute \(\bar{x}^{*b}\).
Compare the fraction of \(\bar{x}^{*b}\) farther from \(\bar{x}\) than \(|\bar{x} - \theta_0|\).

Problem: The bootstrap distribution is centered at \(\bar{x}\), not at \(\theta_0\).
It approximates the sampling distribution of \(\hat{\theta}\), not the null distribution.

Code 
set.seed(551)
n_demo <- 22
x_demo <- rgamma(n_demo, shape = 2, rate = 1)   # true mean ≈ 2
mu_demo <- 1.5
B_demo  <- 4000

xbar_demo <- mean(x_demo)

# WRONG: resample from original, compare distance from xbar
T_naive <- replicate(B_demo, mean(sample(x_demo, n_demo, replace = TRUE)))
p_naive <- mean(abs(T_naive - xbar_demo) >= abs(xbar_demo - mu_demo))

# CORRECT: shift then resample
x_sh_demo <- x_demo - xbar_demo + mu_demo
T_correct <- replicate(B_demo, {
  bs <- sample(x_sh_demo, n_demo, replace = TRUE)
  (mean(bs) - mu_demo) / (sd(bs) / sqrt(n_demo))
})
T_obs_demo <- (xbar_demo - mu_demo) / (sd(x_demo) / sqrt(n_demo))
p_correct <- mean(abs(T_correct) >= abs(T_obs_demo))
p_ttest_demo <- t.test(x_demo, mu = mu_demo)$p.value

p_nv <- ggplot(tibble(T = T_naive), aes(x = T)) +

Key Message

The bootstrap test is the most flexible choice for one-sample problems with non-normal, skewed data — it only requires iid sampling and makes no symmetry assumption. The t-test is optimal when normality holds. Permutation methods will be covered after two-sample inference.

Simulation Study: Comparing t-test and Bootstrap

How well does each method control Type I error, and what is the power, across different population shapes?

Code 
run_onesample_tests <- function(n = 20, delta = 0, dist = "normal", B_inner = 499) {
  x <- switch(dist,
    normal  = rnorm(n, mean = delta),
    skewed  = rexp(n, rate = 1) - 1 + delta,
    heavyt  = rt(n, df = 3) + delta
  )
  mu_0 <- 0

  # 1. Parametric t-test
  p_t <- t.test(x, mu = mu_0)$p.value

  # 2. Bootstrap test (shift-resample)
  x_sh <- x - mean(x) + mu_0
  T_ob <- (mean(x) - mu_0) / (sd(x) / sqrt(n))
  T_bs <- replicate(B_inner, {
    bs <- sample(x_sh, n, replace = TRUE)
    (mean(bs) - mu_0) / (sd(bs) / sqrt(n))
  })
  p_b <- mean(abs(T_bs) >= abs(T_ob))

  c(p_t = p_t, p_boot = p_b)
}

Key Takeaways from Simulation

  • Normal data: Both methods control Type I error well at \(n = 15\) and \(n = 40\); t-test has slightly higher power (it’s optimal here)
  • Skewed data, small \(n\): The t-test can be slightly anti-conservative (Type I error > 5%); the bootstrap test maintains better control
  • Heavy-tailed data (\(t_3\)): Similar pattern — bootstrap is more robust for small samples
  • Large \(n\): Differences wash out — the CLT rescues the t-test regardless of population shape

Practical Implication

For small samples (\(n < 30\)) with non-normal data, the bootstrap test is preferable. For \(n \geq 40\), the t-test is nearly equivalent in practice.

Bootstrap Tests and the Duality with CIs

Bootstrap Tests and Bootstrap CIs: Are They Dual?

In the parametric setting, confidence intervals and tests are exactly dual. For bootstrap methods this is only approximate — and only when the CI and test use the same pivot.

The Key Condition

  • Percentile CI resamples from the original data and uses \(\bar{X}^*\) as the pivot
  • Bootstrap test resamples from the shifted data and uses some test statistic \(T^*\)
  • If both use the same pivot (e.g., raw mean), duality is approximate with only boundary disagreements from Monte Carlo noise
  • If they use different pivots (e.g., percentile CI with raw mean vs. test with standardised \(t\)), they can disagree systematically over a wide range

Demonstrating: Same Pivot vs. Different Pivots

Code 
set.seed(42)
# Right-skewed small sample: CRP values (mg/L)
crp_small <- c(1.2, 1.5, 2.3, 1.8, 4.7, 3.1, 1.4, 6.2, 2.0, 1.6)
n_s   <- length(crp_small)
B_s   <- 9999
xbar_s <- mean(crp_small)

# Percentile CI (pivot: raw mean from original data)
boot_means <- replicate(B_s, mean(sample(crp_small, n_s, replace = TRUE)))
ci_lo <- quantile(boot_means, 0.025)
ci_hi <- quantile(boot_means, 0.975)

mu0_grid <- seq(0.8, 4.8, by = 0.05)

scan_results <- map_dfr(mu0_grid, function(mu0) {
  x_sh <- crp_small - xbar_s + mu0
  in_ci <- mu0 >= ci_lo & mu0 <= ci_hi

  # Same pivot: raw mean difference (matches what percentile CI inverts)
  T_ob_raw <- xbar_s - mu0
  T_bs_raw <- replicate(B_s, mean(sample(x_sh, n_s, replace = TRUE)) - mu0)
  p_raw <- mean(abs(T_bs_raw) >= abs(T_ob_raw))

  # Different pivot: standardised t-statistic
  T_ob_t <- (xbar_s - mu0) / (sd(crp_small) / sqrt(n_s))
  T_bs_t <- replicate(B_s, {
    bs <- sample(x_sh, n_s, replace = TRUE)
    (mean(bs) - mu0) / (sd(bs) / sqrt(n_s))
  })
  p_t <- mean(abs(T_bs_t) >= abs(T_ob_t))

  tibble(mu0      = mu0,
         in_ci    = in_ci,
         p_raw    = p_raw,
         p_t      = p_t,
         agree_raw = in_ci == (p_raw >= 0.05),
         agree_t   = in_ci == (p_t   >= 0.05))
})

  ggplot(data, aes(x = mu0, y = .data[[p_col]])) +

             fill = "#16a085", alpha = 0.12) +

               color = "#16a085", linewidth = 1.0, linetype = "dotted") +

    geom_line(aes(color = .data[[agree_col]]), linewidth = 1.6) +
    geom_point(data = filter(data, !.data[[agree_col]]),
               aes(x = mu0, y = .data[[p_col]]),
               color = "#e74c3c", size = 3) +
    scale_color_manual(values = c("TRUE" = "#006a4e", "FALSE" = "#e74c3c"),
                       labels = c("TRUE" = "Agree", "FALSE" = "Disagree")) +
    annotate("text", x = mean(c(ci_lo, ci_hi)), y = 0.88,

Key Lesson

Left panel: Using the same pivot (raw mean), disagreements are rare and only occur right at the CI boundary due to Monte Carlo variability — duality is approximately satisfied.
Right panel: Using different pivots (percentile CI vs. standardised \(t\)-test), disagreements are systematic and spread over a range — this is a methodological mismatch, not boundary noise.

Key Takeaways

Key Takeaways

Today’s Main Points (C&H Chapter 8)

  1. Bootstrap hypothesis tests approximate the null distribution by resampling from data shifted to satisfy \(H_0\) — this is fundamentally different from bootstrap CIs (which resample from the original data)

  2. The naive bootstrap is wrong: resampling from the original data without shifting produces a distribution centered at \(\bar{x}\), not at \(\mu_0\) — it does not represent the null distribution

  3. One-sample bootstrap test: shift data so \(\bar{x}^* = \theta_0\), resample, compute the t-statistic; the p-value is the fraction of bootstrap statistics as extreme as observed

  4. Bootstrap vs. t-test: the bootstrap requires only iid sampling and no distributional assumptions; benefits are largest at small \(n\) with skewed or heavy-tailed data; both converge for large \(n\)

  5. Duality is approximate, not exact: the bootstrap percentile CI and bootstrap t-test use different pivots, so near CI boundaries with small, skewed samples they can give contradictory decisions — reject by one criterion but not the other
