Lesson 19: Analysis of Paired Data

Review: Lesson 18

Two independent samples (Lesson 18):

  • Two-sample \(z\): \(\sigma_1^2, \sigma_2^2\) known \(\Rightarrow\) pivot \(Z \sim N(0,1)\)
  • Welch \(t\)-test (default): \(\sigma_1^2, \sigma_2^2\) unknown \(\Rightarrow\) \(T_W \approx t_{\hat\nu}\)
  • Pooled \(t\)-test: equal variances assumed \(\Rightarrow\) \(T_P \sim t_{n_1+n_2-2}\) (exact)
  • \(z\)-test for \(p_1 - p_2\); \(F\)-test for \(\sigma_1^2/\sigma_2^2\)

. . .

Today’s Goals:

  1. Recognize when data are paired vs. independent and why it matters
  2. Show how pairing reduces variance when within-pair correlation is positive
  3. Derive and apply the paired \(t\)-test and paired CI for \(\mu_D\) (DBC 10.3)
  4. Understand the link between paired analysis and one-sample inference
  5. Apply to crossover trials, pre/post studies, and matched case-control designs

The Paired Design

When Are Data Paired?

Data are paired when each observation in group 1 is naturally linked to exactly one observation in group 2:

Design Example
Pre/post (same subject) SBP before vs. after 12 weeks of treatment
Crossover trial Same patient receives drug and placebo in random order
Matched case-control Cases matched 1:1 to controls on age and sex
Repeated measurement Lab value at baseline and 6-month follow-up
Bilateral organs Right vs. left eye intraocular pressure

. . .

ImportantThe Critical Distinction

Paired: \(n\) pairs \(\to\) \(n\) differences \(\to\) one-sample problem on \(D_i\)

Independent: \(n_1 + n_2\) separate observations \(\to\) two-sample problem

Applying a two-sample test to paired data ignores within-pair correlation, discards information, and loses power — sometimes substantially.

The Paired Reduction

Setup: \((X_{1i}, X_{2i})\), \(i = 1, \ldots, n\) are \(n\) independent pairs (but within each pair, \(X_{1i}\) and \(X_{2i}\) are correlated).

Define the within-pair difference: \(D_i = X_{1i} - X_{2i}\)

Then \(D_1, \ldots, D_n \stackrel{iid}{\sim}\) some distribution with: \[\mu_D = E[D_i] = \mu_1 - \mu_2 \qquad \sigma_D^2 = \text{Var}(D_i)\]

Everything reduces to one-sample inference on \(D_1, \ldots, D_n\).

. . .

Why the variance is smaller: Let \(\rho = \text{Cor}(X_{1i}, X_{2i})\). Then: \[\sigma_D^2 = \text{Var}(X_{1i} - X_{2i}) = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2\]

When \(\rho > 0\) (the typical case in biological paired designs): \[\sigma_D^2 = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2 \;<\; \sigma_1^2 + \sigma_2^2\]

Pairing removes between-subject noise by differencing within each pair.

Paired \(t\)-Test (DBC 10.3)

Let \(\bar{D} = \frac{1}{n}\sum_{i=1}^n D_i\) and \(S_D^2 = \frac{1}{n-1}\sum_{i=1}^n (D_i - \bar{D})^2\).

Paired \(t\)-statistic for \(H_0: \mu_D = \mu_0\) (usually \(\mu_0 = 0\)): \[T = \frac{\bar{D} - \mu_0}{S_D / \sqrt{n}} \sim t_{n-1}\]

Exact under normality of \(D_i\); approximately valid by CLT for large \(n\).

Paired \(100(1-\alpha)\%\) CI for \(\mu_D\): \[\bar{D} \;\pm\; t_{\alpha/2,\,n-1} \cdot \frac{S_D}{\sqrt{n}}\]

. . .

In R:

t.test(x1, x2, paired = TRUE)   # from two measurement vectors
t.test(d)                        # from pre-computed differences
Note

The paired \(t\)-test is identical to the one-sample \(t\)-test on the differences — all the theory from Lessons 7–8 applies directly.

Variance Reduction: How Much Does Pairing Help?

When \(\sigma_1 = \sigma_2 = \sigma\), the SE of \(\bar{D}\) in the paired analysis is: \[\text{SE}_\text{paired} = \frac{\sigma_D}{\sqrt{n}} = \frac{\sigma\sqrt{2(1-\rho)}}{\sqrt{n}}\]

The SE from an unpaired analysis with the same total \(n\) subjects per group would be: \[\text{SE}_\text{unpaired} = \sigma\sqrt{\frac{2}{n}}\]

The ratio of CI widths (paired to unpaired) is \(\sqrt{1 - \rho}\).

tibble(rho = c(0, 0.3, 0.5, 0.7, 0.8, 0.9)) |>
  mutate(
    width_ratio     = round(sqrt(1 - rho), 3),
    pct_narrower    = scales::percent(1 - sqrt(1 - rho), accuracy = 1)
  ) |>
  knitr::kable(
    col.names = c("rho", "CI width ratio (paired / unpaired)",

Visualizing Variance Reduction by Simulation

Code 
set.seed(551)

sim_ci_width <- function(rho, n = 25, sigma = 10, B = 2000) {
  map_dfr(seq_len(B), function(i) {
    L  <- chol(sigma^2 * matrix(c(1, rho, rho, 1), 2))
    xy <- matrix(rnorm(2 * n), n, 2) %*% L
    d  <- xy[, 1] - xy[, 2]
    tibble(
      paired   = 2 * qt(0.975, n - 1) * sd(d) / sqrt(n),
      unpaired = diff(t.test(xy[, 1], xy[, 2])$conf.int)
    )
  }) |>
    summarise(across(everything(), \(x) mean(x, na.rm = TRUE))) |>
    mutate(rho = rho)
}

widths <- map_dfr(c(0, 0.3, 0.5, 0.7, 0.8, 0.9), sim_ci_width)

widths |>
  pivot_longer(c(paired, unpaired), names_to = "Method", values_to = "Width") |>
  mutate(Method = str_to_title(Method)) |>
  ggplot(aes(x = factor(rho), y = Width, fill = Method)) +
  geom_col(position = "dodge", width = 0.55) +
  scale_fill_manual(values = c("Paired" = "#006a4e", "Unpaired" = "#e74c3c")) +
  labs(
    title    = "Mean 95% CI Width: Paired vs. Unpaired t-test",
    subtitle = bquote("Benefit grows with within-pair correlation" ~ rho ~
                      " (n = 25," ~ sigma ~ "= 10 per group, 2000 simulations)"),
    x        = expression("Within-pair correlation " * rho),
    y        = "Mean 95% CI Width",
    fill     = NULL
  ) +
  theme(legend.position = "bottom")

Crossover Trial: Antihypertensive Drug vs. Placebo

Study (DBC 10.3 style): 20 hypertensive patients complete a crossover trial. Each receives both an antihypertensive drug and placebo (random order, 4-week washout). Outcome: systolic BP reduction (mmHg). Test \(H_0: \mu_D = 0\) vs. \(H_a: \mu_D < 0\) (drug lowers BP more than placebo) at \(\alpha = 0.05\).

What If We Incorrectly Used a Two-Sample Test?

paired_res   <- t.test(sbp_drug, sbp_placebo, paired = TRUE, alternative = "less")
unpaired_res <- t.test(sbp_drug, sbp_placebo, paired = FALSE, alternative = "less")

            paired_res$parameter,

            unpaired_res$statistic,

            unpaired_res$p.value))
  t = -1.907,  df = 38.0,  p = 0.03207
cat(sprintf("  95%% CI: (%.2f, %.2f)\n",

. . .

The paired test has a much narrower CI and smaller p-value because it removes between-patient variability (\(\rho = 0.75\)). The unpaired test wastes information by treating the two arms as unrelated samples.

t.test(cases, controls, paired = TRUE) is equivalent to t.test(d_match). The 1:1 matching creates the pairing structure, and the analysis must respect it — ignoring the matching (unpaired test) would discard the correlation induced by matching on age and sex.

Paired Analysis Checklist

Before choosing paired vs. two-sample analysis, confirm:

  1. 1-to-1 link exists: same subject measured twice, or two subjects deliberately matched
  2. Within-pair correlation is positive: almost always true for biological measurements on the same individual
  3. \(n\) = number of pairs, not total observations — paired \(t\)-test has \(n - 1\) df, not \(2n - 2\)
  4. \(D_i\) approximately normal (or \(n\) large enough for CLT)

. . .

WarningCommon Mistake

Reporting “\(n_1 = n_2 = 20\)” for a pre/post study and running t.test(pre, post) without paired = TRUE. This treats \(2n = 40\) observations as independent, underestimates the SE, and produces an invalid test. The correct \(n\) is 20 pairs, df = 19.

Key Takeaways

Key Takeaways (DBC 10.3)

ImportantPaired Data: Main Points

  1. Paired designs arise from pre/post measurements, crossover trials, bilateral organs, and matched studies; each pair yields one difference \(D_i = X_{1i} - X_{2i}\)

  2. Variance reduction: \(\text{Var}(D_i) = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2\); with \(\sigma_1 = \sigma_2 = \sigma\), the CI width ratio (paired/unpaired) is \(\sqrt{1 - \rho}\) — pairing eliminates between-subject noise when \(\rho > 0\)

  3. Paired \(t\)-test: \(T = \bar{D}/(S_D/\sqrt{n}) \sim t_{n-1}\); identical to one-sample \(t\) on the \(D_i\); exact under normality of \(D_i\), approximately valid by CLT for moderate \(n\)

  4. Always use paired = TRUE in R when the design is paired — omitting it ignores correlation, widens CIs, and reduces power

  5. Check normality of \(D_i\) (not of \(X_{1i}\) or \(X_{2i}\)) with a histogram and Q-Q plot; for small \(n\) with non-normal \(D_i\), use nonparametric alternatives (Lesson 21)
