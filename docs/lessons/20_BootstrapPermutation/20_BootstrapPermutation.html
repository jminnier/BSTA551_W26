Motivating Example

Trauma registry: Compare hospital length of stay (LOS, days) between blunt and penetrating trauma patients. LOS is strongly right-skewed and \(n\) is moderate: the Welch \(t\)-test CI may be unreliable. Bootstrap and permutation give valid inference with no distributional assumptions.

Two-Sample Bootstrap CI

The Two-Sample Bootstrap Algorithm (C&H 3.2)

Setup: Independent samples \(x_1, \ldots, x_{n_1}\) from \(F_1\) and \(y_1, \ldots, y_{n_2}\) from \(F_2\).

Goal: CI for \(\theta = g(F_1, F_2)\), e.g., \(\mu_1 - \mu_2\), \(\text{median}_1 - \text{median}_2\), \(\sigma_1 / \sigma_2\).

Algorithm: for \(b = 1, \ldots, B\):

  1. Draw \(x_1^{*b}, \ldots, x_{n_1}^{*b}\) with replacement from \(\{x_1, \ldots, x_{n_1}\}\)
  2. Draw \(y_1^{*b}, \ldots, y_{n_2}^{*b}\) with replacement from \(\{y_1, \ldots, y_{n_2}\}\)
  3. Compute \(\hat\theta^{*b} = g(\mathbf{x}^{*b}, \mathbf{y}^{*b})\)

Percentile CI: \(\bigl(\hat\theta^*_{(\alpha/2)},\; \hat\theta^*_{(1-\alpha/2)}\bigr)\)

Basic (reflection) CI: \(\bigl(2\hat\theta - \hat\theta^*_{(1-\alpha/2)},\; 2\hat\theta - \hat\theta^*_{(\alpha/2)}\bigr)\)

Key Point

Resample each group separately and independently — this preserves the two-group structure and approximates the sampling distribution of \(\hat\theta_1 - \hat\theta_2\). Pooling before resampling would impose \(H_0\) (that is permutation, not bootstrap).

Computing the Bootstrap CI

set.seed(551)
B        <- 5000
n1       <- length(los_blunt)
n2       <- length(los_penet)
obs_diff <- mean(los_blunt) - mean(los_penet)

boot_diffs <- replicate(B, {
  mean(sample(los_blunt, n1, replace = TRUE)) -
  mean(sample(los_penet, n2, replace = TRUE))
})

Two-Sample Permutation Test

The Permutation Test: Core Idea (C&H Ch. 5)

Null hypothesis: \(H_0: F_1 = F_2\) — the two groups have the same distribution.

Under \(H_0\), the group label on each observation is arbitrary (exchangeable). Any assignment of the \(N = n_1 + n_2\) pooled observations into groups of size \(n_1\) and \(n_2\) is equally likely.

Algorithm: for \(b = 1, \ldots, B\):

  1. Pool all \(N\) observations
  2. Randomly permute labels: assign the first \(n_1\) to group 1, the rest to group 2
  3. Compute \(T^{*b}\) (the test statistic under the permuted labeling)

Two-sided p-value: \(\;\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}\bigl(|T^{*b}| \geq |T_\text{obs}|\bigr)\)

Bootstrap vs. Permutation — The Essential Distinction

Bootstrap CI Permutation test
Purpose Estimate variability Test \(H_0\)
Resamples from Each group separately Pooled data (relabeling)
Approximates Sampling distribution of \(\hat\theta\) Null distribution of \(T\)
\(H_0\) imposed? No Yes (\(F_1 = F_2\))

Permutation Test: Implementation

set.seed(551)
B_perm  <- 9999
all_los <- c(los_blunt, los_penet)
N       <- length(all_los)
t_obs   <- mean(los_blunt) - mean(los_penet)

perm_diffs <- replicate(B_perm, {
  idx <- sample(N)
  mean(all_los[idx[seq_len(n1)]]) - mean(all_los[idx[(n1 + 1):N]])
})

p_perm  <- mean(abs(perm_diffs) >= abs(t_obs))
p_welch <- t.test(los_blunt, los_penet)$p.value

cat(sprintf("Observed mean difference:   %.3f days\n", t_obs))
Observed mean difference:   1.070 days
cat(sprintf("Permutation p-value:        %.4f\n",      p_perm))
Permutation p-value:        0.4551
cat(sprintf("Welch t-test p-value:       %.4f\n",      p_welch))
Welch t-test p-value:       0.4749

Permutation Tests Work with Any Statistic

set.seed(551)

# Permutation test for difference in MEDIANS
t_obs_med <- median(los_blunt) - median(los_penet)
perm_med  <- replicate(9999, {
  idx <- sample(N)
  median(all_los[idx[seq_len(n1)]]) - median(all_los[idx[(n1 + 1):N]])
})
p_perm_med <- mean(abs(perm_med) >= abs(t_obs_med))

cat(sprintf("Median difference: %.3f   permutation p = %.4f\n",
            t_obs_med, p_perm_med))
Median difference: 2.003   permutation p = 0.2916
# Permutation test for VARIANCE RATIO (vs F-test)
t_obs_var <- var(los_blunt) / var(los_penet)
perm_var  <- replicate(9999, {
  idx <- sample(N)
  var(all_los[idx[seq_len(n1)]]) / var(all_los[idx[(n1 + 1):N]])
})
p_perm_var <- mean(perm_var >= t_obs_var | perm_var <= 1 / t_obs_var)
p_ftest    <- var.test(los_blunt, los_penet)$p.value

cat(sprintf("Variance ratio:    %.3f   permutation p = %.4f   F-test p = %.4f\n",
            t_obs_var, p_perm_var, p_ftest))
Variance ratio:    0.605   permutation p = 1.0000   F-test p = 0.1426

The permutation test for the variance ratio is valid regardless of distribution shape, unlike the \(F\)-test, which requires normality.

Bootstrap for Paired Data

Paired Bootstrap CI

For paired data, the bootstrap resamples entire pairs \((D_i)\) with replacement which preserves the pairing structure.

Algorithm: for \(b = 1, \ldots, B\):

  1. Draw \(D_1^{*b}, \ldots, D_n^{*b}\) with replacement from \(\{D_1, \ldots, D_n\}\)
  2. Compute \(\bar{D}^{*b} = \frac{1}{n}\sum D_i^{*b}\)

Percentile CI: \(\bigl(\bar{D}^*_{(\alpha/2)},\; \bar{D}^*_{(1-\alpha/2)}\bigr)\)

No normality assumption on \(D_i\).

# Crossover trial differences from Lesson 19
set.seed(42)
n_pair <- 20; rho_p <- 0.75
L_p    <- chol(10^2 * matrix(c(1, rho_p, rho_p, 1), 2))
xy_p   <- matrix(rnorm(2 * n_pair), n_pair, 2) %*% L_p +
          matrix(c(0, -10), n_pair, 2, byrow = TRUE)
d_cross <- xy_p[, 2] - xy_p[, 1]

set.seed(551)
boot_D         <- replicate(5000, mean(sample(d_cross, n_pair, replace = TRUE)))
ci_boot_paired <- quantile(boot_D, c(0.025, 0.975))
ci_t_paired    <- t.test(d_cross)$conf.int

cat(sprintf("Paired t-test 95%% CI:  (%.3f, %.3f)\n",
            ci_t_paired[1], ci_t_paired[2]))
Paired t-test 95% CI:  (-15.362, -9.182)
cat(sprintf("Bootstrap    95%% CI:  (%.3f, %.3f)\n",
            ci_boot_paired[1], ci_boot_paired[2]))
Bootstrap    95% CI:  (-15.012, -9.408)

With approximately normal differences and moderate \(n\), the two CIs are very similar. The bootstrap shines when \(D_i\) are clearly non-normal or \(n\) is very small.

Comparing Methods: Simulation

Type I Error and Power: Welch t-test vs. Permutation Test

The permutation test derives its null distribution empirically rather than from the \(t\)-distribution. For the mean difference statistic, how much does it matter?

Code 
set.seed(551)
B_sim  <- 3000
B_perm <- 499

# chi-squared(2): mean = 2, heavily right-skewed (skewness = 2*sqrt(2) ~ 2.8)
# shifted to mean 0 for fair comparison
sim_scenario <- function(dist_fn, n = 10, effect = 0) {
  replicate(B_sim, {
    x1  <- dist_fn(n)
    x2  <- dist_fn(n) + effect
    Ns  <- 2 * n
    all <- c(x1, x2)
    t0  <- mean(x1) - mean(x2)
    p_welch <- t.test(x1, x2)$p.value
    p_perm  <- {
      perms <- replicate(B_perm, {
        idx <- sample(Ns)
        mean(all[idx[seq_len(n)]]) - mean(all[idx[(n + 1):Ns]])
      })
      mean(abs(perms) >= abs(t0))
    }
    c(Welch = p_welch, Permutation = p_perm)
  }) |> t() |> as_tibble() |>
    summarise(across(everything(), \(x) mean(x < 0.05)))
}

norm_fn <- \(n) rnorm(n, 0, 1)
skew_fn <- \(n) rchisq(n, df = 2) - 2   # shifted chi-sq(2), mean = 0

results <- bind_rows(
  bind_rows(
    sim_scenario(norm_fn, n = 10, effect = 0.0) |> mutate(Scenario = "Type I Error (effect = 0)"),
    sim_scenario(norm_fn, n = 10, effect = 1.0) |> mutate(Scenario = "Power (effect = 1 SD)")
  ) |> mutate(Distribution = "Normal(0,1) — symmetric"),
  bind_rows(
    sim_scenario(skew_fn, n = 10, effect = 0.0) |> mutate(Scenario = "Type I Error (effect = 0)"),
    sim_scenario(skew_fn, n = 10, effect = 1.0) |> mutate(Scenario = "Power (effect = 1 SD)")
  ) |> mutate(Distribution = "chi-sq(2) shifted — heavily right-skewed")
)

results |>
  pivot_longer(c(Welch, Permutation),
               names_to = "Method", values_to = "Rate") |>
  mutate(
    Scenario     = factor(Scenario,
                          levels = c("Type I Error (effect = 0)",
                                     "Power (effect = 1 SD)")),
    Distribution = factor(Distribution,
                          levels = c("Normal(0,1) — symmetric",
                                     "chi-sq(2) shifted — heavily right-skewed"))
  ) |>
  ggplot(aes(x = Method, y = Rate, fill = Method)) +
  geom_col(width = 0.5) +
  geom_hline(
    data = tibble(
      Scenario = factor("Type I Error (effect = 0)",
                        levels = c("Type I Error (effect = 0)", "Power (effect = 1 SD)")),
      y = 0.05
    ),
    aes(yintercept = y),
    linetype = "dashed", linewidth = 1.2, color = "black"
  ) +
  geom_text(aes(label = scales::percent(Rate, accuracy = 0.1)),
            vjust = -0.4, size = 4.5, fontface = "bold") +
  facet_grid(Distribution ~ Scenario) +
  scale_fill_manual(values = c("Welch" = "#006a4e", "Permutation" = "#e74c3c")) +
  scale_y_continuous(labels = scales::percent, limits = c(0, 0.95)) +
  labs(
    title    = "Welch t-test vs. Permutation Test  (n = 10 per group, 3000 simulations)",
    subtitle = "Both methods control Type I error near 5% and have similar power — permutation's advantage is flexibility.",
    x = NULL, y = "Rejection Rate", fill = NULL
  ) +
  theme(legend.position = "bottom",
        strip.text = element_text(size = 12))

Note

The two-sided Welch \(t\)-test is robust to skewness for Type I error even at small \(n\): skewness makes each tail individually wrong, but in a two-sided test the errors in the two tails largely cancel. The simulation below confirms this — the two methods agree closely. Permutation’s advantage is generality: it works with any test statistic, not just means.

Key Takeaways

Key Takeaways (C&H Ch. 3, 5; DBC 10.6)

Bootstrap and Permutation for Two Samples

  1. Two-sample bootstrap CI: Resample each group independently with replacement; construct percentile or basic CI. Works for any statistic — means, medians, SD ratios, etc. No distributional assumption

  2. Permutation test: Pool all \(N\) observations, relabel groups at random; fraction of permuted statistics \(\geq |T_\text{obs}|\) gives a valid p-value under \(H_0: F_1 = F_2\) (exchangeability)

  3. Bootstrap \(\neq\) permutation: Bootstrap approximates the sampling distribution of \(\hat\theta\) (for CIs); permutation approximates the null distribution of \(T\) (for testing); they solve different problems and use data differently

  4. Paired bootstrap: Resample whole pairs \((D_i)\) to preserve the pairing structure; produces CI for \(\mu_D\) without normality assumption

  5. When to prefer resampling: Small \(n\) with non-normal data; non-standard statistics with no closed-form SE; any setting where parametric assumptions are doubtful
