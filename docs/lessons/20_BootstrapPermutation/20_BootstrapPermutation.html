NoteMotivating Example

Trauma registry: Compare hospital length of stay (LOS, days) between blunt and penetrating trauma patients. LOS is strongly right-skewed and \(n\) is moderate: the Welch \(t\)-test CI may be unreliable. Bootstrap and permutation give valid inference with no distributional assumptions.

Two-Sample Bootstrap CI

The Two-Sample Bootstrap Algorithm (C&H 3.2)

Setup: Independent samples \(x_1, \ldots, x_{n_1}\) from \(F_1\) and \(y_1, \ldots, y_{n_2}\) from \(F_2\).

Goal: CI for \(\theta = g(F_1, F_2)\), e.g., \(\mu_1 - \mu_2\), \(\text{median}_1 - \text{median}_2\), \(\sigma_1 / \sigma_2\).

Algorithm: for \(b = 1, \ldots, B\):

  1. Draw \(x_1^{*b}, \ldots, x_{n_1}^{*b}\) with replacement from \(\{x_1, \ldots, x_{n_1}\}\)
  2. Draw \(y_1^{*b}, \ldots, y_{n_2}^{*b}\) with replacement from \(\{y_1, \ldots, y_{n_2}\}\)
  3. Compute \(\hat\theta^{*b} = g(\mathbf{x}^{*b}, \mathbf{y}^{*b})\)

Percentile CI: \(\bigl(\hat\theta^*_{(\alpha/2)},\; \hat\theta^*_{(1-\alpha/2)}\bigr)\)

Basic (reflection) CI: \(\bigl(2\hat\theta - \hat\theta^*_{(1-\alpha/2)},\; 2\hat\theta - \hat\theta^*_{(\alpha/2)}\bigr)\)

Bootstrap SE CI: \(\hat\theta \;\pm\; z_{\alpha/2} \cdot \widehat{\text{SE}}_{\text{boot}}\), where \(\widehat{\text{SE}}_{\text{boot}} = \text{sd}(\hat\theta^{*1}, \ldots, \hat\theta^{*B})\)

. . .

ImportantKey Point

Resample each group separately and independently — this preserves the two-group structure and approximates the sampling distribution of \(\hat\theta_1 - \hat\theta_2\). Pooling before resampling would impose \(H_0\): that is permutation, not bootstrap.

Two-Sample Bootstrap Hypothesis Test

Bootstrap Testing: The Core Challenge

Recall from Lesson 17: for a one-sample bootstrap test of \(H_0: \mu = \mu_0\), we shift the sample to satisfy \(H_0\) before resampling, then compare the observed statistic to the shifted null distribution.

For two samples, we test \(H_0: \theta_1 = \theta_2\) (e.g., \(\mu_1 = \mu_2\)). The same logic applies: we must resample in a way that imposes \(H_0\).

. . .

WarningWhy Not Just Use the Bootstrap Distribution?

If we simply computed the distribution of \(\hat\theta^* = \hat\mu_1^* - \hat\mu_2^*\) by resampling each group, we would get the sampling distribution centered at the observed \(\hat\Delta = \hat\mu_1 - \hat\mu_2\).

This gives us a confidence interval — but not a p-value under \(H_0\). The null distribution must be centered at \(0\).

Two-Sample Bootstrap Test: The Shift Method (C&H 8.2)

Setup: Test \(H_0: \mu_1 = \mu_2\) vs \(H_a: \mu_1 \neq \mu_2\).

Step 1: Impose \(H_0\) by centering both samples at the same mean:

\[\tilde{x}_i = x_i - \bar{x} + \bar{X}_{\text{pool}}, \qquad \tilde{y}_j = y_j - \bar{y} + \bar{X}_{\text{pool}}\]

where \(\bar{X}_{\text{pool}} = \frac{n_1 \bar{x} + n_2 \bar{y}}{n_1 + n_2}\) is the pooled mean.

Now \(\tilde{x}\) and \(\tilde{y}\) have the same mean — \(H_0\) is satisfied.

. . .

Step 2: Generate the null distribution by resampling from the shifted samples:

for \(b = 1, \ldots, B\):

  1. Draw \(\tilde{x}^{*b}\) (size \(n_1\)) from \(\{\tilde{x}_i\}\) with replacement
  2. Draw \(\tilde{y}^{*b}\) (size \(n_2\)) from \(\{\tilde{y}_j\}\) with replacement
  3. Compute \(T^{*b} = \bar{\tilde{x}}^{*b} - \bar{\tilde{y}}^{*b}\)

p-value: \(\hat{p} = \frac{1}{B}\sum_{b=1}^{B} \mathbf{1}\bigl(|T^{*b}| \geq |T_\text{obs}|\bigr)\)

where \(T_\text{obs} = \bar{x} - \bar{y}\).

Two-Sample Bootstrap Test: Implementation

set.seed(551)
B_test <- 9999

# Observed test statistic
t_obs <- mean(los_blunt) - mean(los_penet)

# Step 1: Shift samples to satisfy H0 (equal means)
grand_mean <- (sum(los_blunt) + sum(los_penet)) / (n1 + n2)
x_shift    <- los_blunt - mean(los_blunt) + grand_mean
y_shift    <- los_penet - mean(los_penet) + grand_mean

cat(sprintf("Before shifting:  mean(blunt) = %.3f, mean(penet) = %.3f\n",
            mean(los_blunt), mean(los_penet)))
Before shifting:  mean(blunt) = 7.859, mean(penet) = 5.624
cat(sprintf("After  shifting:  mean(x_shift)= %.3f, mean(y_shift)= %.3f\n",
            mean(x_shift), mean(y_shift)))
After  shifting:  mean(x_shift)= 6.901, mean(y_shift)= 6.901
# Step 2: Resample from shifted samples
boot_null <- replicate(B_test, {
  mean(sample(x_shift, n1, replace = TRUE)) -
  mean(sample(y_shift, n2, replace = TRUE))
})

p_boot  <- mean(abs(boot_null) >= abs(t_obs))

TipPractical Note

For testing mean differences specifically, the permutation test (next section) is often preferred over the shift-bootstrap — it is simpler, exact under exchangeability, and avoids the need to carefully define “imposing \(H_0\).” The bootstrap test shines for non-location statistics where permutation is not straightforwardly applicable.

Two-Sample Permutation Test

The Permutation Test: Core Idea (C&H Ch. 5)

Null hypothesis: \(H_0: F_1 = F_2\) — the two groups have the same distribution.

Under \(H_0\), the group label on each observation is arbitrary (exchangeable). Any assignment of the \(N = n_1 + n_2\) pooled observations into groups of size \(n_1\) and \(n_2\) is equally likely.

. . .

Algorithm: for \(b = 1, \ldots, B\):

  1. Pool all \(N\) observations
  2. Randomly permute labels: assign the first \(n_1\) to group 1, the rest to group 2
  3. Compute \(T^{*b}\) (the test statistic under the permuted labeling)

Two-sided p-value: \(\;\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}\bigl(|T^{*b}| \geq |T_\text{obs}|\bigr)\)

. . .

When Is the Permutation Test Valid?

The permutation test is valid (exact Type I error control) when the observations are exchangeable under \(H_0\).

ImportantExchangeability: What It Means

Observations \(X_1, \ldots, X_{n_1}, Y_1, \ldots, Y_{n_2}\) are exchangeable under \(H_0\) if permuting group labels does not change the joint distribution. This holds when:

\[H_0: F_1 = F_2 \quad \text{(identical distributions)}\]

If \(H_0\) is true, any relabeling of the pooled data is just as likely as any other — permuting is valid.

. . .

When exchangeability holds:

  • Randomized experiments: treatment assigned at random, so under \(H_0\) labels are arbitrary
  • Observational data: valid if groups differ only in the parameter of interest (strong assumption)
  • Testing \(H_0: F_1 = F_2\) exactly (not just equal means)

When exchangeability fails (permutation test is invalid):

  • Groups differ in variance or shape but not in means: permuting is not valid for a test of means because \(F_1 \neq F_2\) even under the mean-equality \(H_0\)
  • Paired or clustered data: pairing creates dependence — don’t ignore the structure
  • Confounding: if groups also differ on covariates, labels are not exchangeable

Exchangeability in Practice: What Hypothesis Are We Testing?

WarningA Subtle Point

The permutation test is an exact test of \(H_0: F_1 = F_2\). When used with the mean difference as the test statistic, it also has good power to detect \(\mu_1 \neq \mu_2\).

However, if the groups differ in variance but not in mean, the permutation test (using the mean difference as the statistic) can have inflated Type I error because the null \(F_1 = F_2\) includes equal variances. Rejecting \(H_0: F_1 = F_2\) does not tell us why it was rejected.

Solutions:

  • If you care only about means: use the Welch \(t\)-test (robust to unequal variances) or the bootstrap test (shift method)
  • If you want a permutation test for means when variances may differ: use a standardized test statistic (Welch-type) but permute — this has approximately valid Type I error
  • Reserve permutation tests for settings where \(F_1 = F_2\) is a plausible and scientifically meaningful null

Bootstrap for Paired Data

Paired Data: Setup and the Crossover Trial Example

Paired data arises when each subject provides two measurements:

  • Crossover trials: same patient receives both treatments (in random order)
  • Before-after studies: same patient measured at two time points
  • Matched cohort studies: pairs matched on confounders

The natural estimand is \(\mu_D = E[D_i]\) where \(D_i = X_{i,\text{post}} - X_{i,\text{pre}}\) (or Treatment \(-\) Control).

Paired Bootstrap CI

For paired data, the bootstrap resamples entire pairs \((D_i)\) with replacement, which preserves the pairing structure.

Algorithm: for \(b = 1, \ldots, B\):

  1. Draw \(D_1^{*b}, \ldots, D_n^{*b}\) with replacement from \(\{D_1, \ldots, D_n\}\)
  2. Compute \(\bar{D}^{*b} = \frac{1}{n}\sum D_i^{*b}\)

Percentile CI: \(\bigl(\bar{D}^*_{(\alpha/2)},\; \bar{D}^*_{(1-\alpha/2)}\bigr)\)

No normality assumption on \(D_i\).

d_cross <- bp_data$diff

set.seed(551)
boot_D         <- replicate(5000, mean(sample(d_cross, n_pair, replace = TRUE)))
ci_boot_paired <- quantile(boot_D, c(0.025, 0.975))
ci_t_paired    <- t.test(d_cross)$conf.int

cat(sprintf("Observed mean difference:    %.3f mmHg\n", mean(d_cross)))
Observed mean difference:    -2.921 mmHg
cat(sprintf("Bootstrap SE:                %.3f\n", sd(boot_D)))
Bootstrap SE:                1.207
cat(sprintf("Paired t-test  95%% CI: (%.3f, %.3f)\n",
            ci_t_paired[1], ci_t_paired[2]))
Paired t-test  95% CI: (-5.508, -0.333)
cat(sprintf("Bootstrap      95%% CI: (%.3f, %.3f)\n",
            ci_boot_paired[1], ci_boot_paired[2]))
Bootstrap      95% CI: (-5.260, -0.555)

With approximately normal differences and moderate \(n\), the two CIs are very similar. The bootstrap shines when \(D_i\) are clearly non-normal or \(n\) is very small.

Paired Bootstrap Test

To test \(H_0: \mu_D = 0\), we must shift the differences to satisfy \(H_0\):

\[\tilde{D}_i = D_i - \bar{D}\]

Now \(\{\tilde{D}_i\}\) have mean exactly 0 — \(H_0\) is imposed. We then resample from the shifted differences.

Algorithm: for \(b = 1, \ldots, B\):

  1. Draw \(\tilde{D}_1^{*b}, \ldots, \tilde{D}_n^{*b}\) with replacement from \(\{\tilde{D}_i\}\)
  2. Compute \(T^{*b} = \bar{\tilde{D}}^{*b}\)

p-value: \(\hat{p} = \frac{1}{B}\sum_{b=1}^B \mathbf{1}\bigl(|T^{*b}| \geq |\bar{D}_\text{obs}|\bigr)\)

set.seed(551)
B_paired <- 9999
D_obs    <- mean(d_cross)

# Shift differences to mean 0 (imposing H0)
d_shifted <- d_cross - mean(d_cross)

cat(sprintf("Before shifting: mean(D) = %.4f\n", mean(d_cross)))
Before shifting: mean(D) = -2.9206
cat(sprintf("After  shifting: mean(D_shift) = %.6f\n", mean(d_shifted)))
After  shifting: mean(D_shift) = 0.000000
# Resample from shifted differences
boot_null_D <- replicate(B_paired,
                         mean(sample(d_shifted, n_pair, replace = TRUE)))

p_boot_paired <- mean(abs(boot_null_D) >= abs(D_obs))
p_t_paired    <- t.test(d_cross)$p.value

cat(sprintf("\nObserved mean difference:       %.3f mmHg\n", D_obs))

Observed mean difference:       -2.921 mmHg
cat(sprintf("Bootstrap test p-value:         %.4f\n",       p_boot_paired))
Bootstrap test p-value:         0.0154
cat(sprintf("Paired t-test p-value:          %.4f\n",       p_t_paired))
Paired t-test p-value:          0.0286

The infer Package

The infer Package: Tidy Resampling Inference

The infer package (part of the tidymodels ecosystem) provides a unified, pipe-friendly framework for hypothesis testing and interval estimation via simulation.

The workflow follows four consistent verbs:

Step Verb What it does
1 specify() Declare the response (and optional explanatory) variable
2 hypothesize() State the null hypothesis (for tests only)
3 generate() Generate bootstrap samples or permutations
4 calculate() Compute the statistic of interest

Then use get_p_value(), get_confidence_interval(), or visualize() to summarize.

NoteWhy Use infer?
  • Consistent syntax across one-sample, two-sample, and paired settings
  • Integrates naturally with dplyr pipelines and tidy data
  • Makes the conceptual steps explicit: specify → hypothesize → generate → calculate
  • Excellent for teaching and reproducible research workflows

Two-Sample Bootstrap Test with infer: A Limitation

Warninginfer does NOT implement the shift-bootstrap for two-sample tests

generate(type = "bootstrap") with hypothesize(null = "independence") resamples each group separately with replacement — exactly the same as the CI bootstrap. The null distribution is centered at the observed difference, not at 0. Calling get_p_value() on this distribution is essentially asking “what fraction of bootstrap samples are at least as extreme as the observed value?” — against a distribution centered at the observed value — which returns a meaningless p-value near 0.5 or higher.

The shift-bootstrap (C&H Ch. 8) must be implemented manually (as shown earlier in these slides). For two-sample hypothesis testing in infer, always use type = "permute".

Comparing Methods: Simulation

Type I Error and Power: Welch t-test vs. Permutation Test

The permutation test derives its null distribution empirically rather than from the \(t\)-distribution. For the mean difference statistic, how much does it matter?

Code 
set.seed(551)
B_sim  <- 3000
B_perm <- 499

sim_scenario <- function(dist_fn, n = 10, effect = 0) {
  replicate(B_sim, {
    x1  <- dist_fn(n)
    x2  <- dist_fn(n) + effect
    Ns  <- 2 * n
    all <- c(x1, x2)
    t0  <- mean(x1) - mean(x2)
    p_welch <- t.test(x1, x2)$p.value
    p_perm  <- {
      perms <- replicate(B_perm, {
        idx <- sample(Ns)
        mean(all[idx[seq_len(n)]]) - mean(all[idx[(n + 1):Ns]])
      })
      mean(abs(perms) >= abs(t0))
    }
    c(Welch = p_welch, Permutation = p_perm)
  }) |> t() |> as_tibble() |>
    summarise(across(everything(), \(x) mean(x < 0.05)))
}

norm_fn <- \(n) rnorm(n, 0, 1)
skew_fn <- \(n) rchisq(n, df = 2) - 2

results <- bind_rows(

    sim_scenario(skew_fn, n = 10, effect = 1.0) |> mutate(Scenario = "Power (effect = 1 SD)")
  ) |> mutate(Distribution = "chi-sq(2) shifted \u2014 heavily right-skewed")
)

The two-sided Welch \(t\)-test is robust to skewness for Type I error even at small \(n\): skewness makes each tail individually wrong, but in a two-sided test the errors largely cancel. Permutation’s advantage is generality: it works with any test statistic, not just means.

Key Takeaways

Key Takeaways (C&H Ch. 3, 5, 8; DBC 10.6)

ImportantBootstrap and Permutation for Two Samples

  1. Two-sample bootstrap CI: Resample each group independently with replacement; construct percentile, basic, or SE CI. Works for any statistic. No distributional assumption.

  2. Two-sample bootstrap test: Shift both samples to satisfy \(H_0\) (equal grand mean), then resample to generate null distribution. Use when permutation assumptions are not met.

  3. Permutation test: Pool all \(N\) observations, relabel groups at random; fraction of permuted statistics \(\geq |T_\text{obs}|\) gives a valid p-value under \(H_0: F_1 = F_2\) (exchangeability). Most natural for randomized experiments.

  4. Permutation validity: Requires exchangeability — groups can only differ in label, not in variance or shape, under \(H_0\). Fails for paired/clustered data and when groups differ on nuisance parameters.

  5. Paired bootstrap CI: Resample whole pairs/differences to preserve pairing; CI for \(\mu_D\) with no normality assumption.

  6. Paired bootstrap test: Shift differences to mean 0 (imposing \(H_0: \mu_D = 0\)), then resample; gives valid p-value without normality.

  7. infer package: Unified specify → hypothesize → generate → calculate pipeline. Use type = "permute" for two-sample tests and type = "bootstrap" for CIs and one-sample tests. The shift-bootstrap for two-sample testing must be coded manually.
